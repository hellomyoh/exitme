## 페르소나별 검토

### Backend/Quant (SA-quant)

- **R1 워밍업**: σ_ref(250일 σ_down 이력)+MA200 → 최소 약 270 거래일 필요, 미충족 시 동작 미정의. 실패 조건: 100 거래일 데이터로 배치가 완주하며 주문표 생성. (근거: trade_algorithm_final.md §3·§10)
- **R2 σ_down→0**: 20일 무하락 시 E 발산/NaN. 실패 조건: 무하락 합성 시계열에서 E=NaN/inf. (근거: §5.1)
- **R3 레짐 전이**: Bear 이탈+Bull 진입 동시 충족 시 규칙 부재, 초기 상태 미규정. (근거: §4)
- **R4 전술 트랙 지표**: §3은 지표를 KODEX 200 기준으로 규정하나 §7 전술 트랙 Close는 레버리지 가격 — 스케일 불일치로 조건 고착. (근거: §3·§7)
- **R5 장중 트리거**: σ20은 종가 확정 후 산출 — 장중 감시 정의 불가. 갭 필터 실행 주체(시스템 v1 실주문 없음) 불명. (근거: §8)
- **R6 수량 산출**: 3단 배분비·정수 반올림·호가단위(5원)·현금 버퍼 미정의. 밴드 ±5%p가 그리드 신규매수에 적용되면 영구 정지 구간 발생. (근거: §6.1·§5.3)
- **R7 익절가 회계**: BuyPrice가 로트 단가인지 평단인지, Grid가 체결일 스냅샷인지 미정의. 코어 물량의 중립 편입 기준가 부재. (근거: §6.2)
- **R8 휴장·정지**: 지표 창의 정지일 처리, 거래일 캘린더 출처, 주문 이월 규칙 부재. REQUIREMENTS §11-1 골든 수치의 출처가 정본이 아닌 basic_trade.md. (근거: §8, REQUIREMENTS §11)

### QA (SA-qa)

- 골든 G1~G3(그리드 3단·중립 익절·배분 3점), 경계 B1~B7(전이 전수, 완충 경계 정확값, 휩쏘 무전이, 갭 필터 경계 ≤, 잔여예산 — 초과 단계는 생성 자체 금지, E=1.0 경계, 밴드 5.0/5.1%p), 재현성 R1~R3(주문표 해시, 백테스트=시그널 바이트 동일, 절제 플래그 독립성 diff), 실패 안전 F1~F2(웜업 부족 시 부분 주문표 저장 금지, 배치 실패 시 전일 주문표 재사용 금지).
- 명세 공백 5건은 SA-quant의 R2·R3·R6과 중복 수렴 + σ_ref 짝수 표본 중위값 정의, 전술 1·2차 동시 충족 분할.

## 쟁점과 충돌

1. **장중 트리거(R5)**: 명세는 장중 감시를 요구하나 v1은 실주문이 없고 σ20은 종가 지표 — 기능 요구와 산출 가능성이 충돌. → 장중 감시를 폐기하고 "전일 확정값 기반 조건부 지시문"으로 주문표에 사전 명기(백테스트는 익일 시가 1회 평가)로 조정.
2. **밴드 vs 그리드(R6)**: 밴드를 그리드에 적용하면 목표 미달 4%p 구간에서 매수 영구 정지. → 밴드는 리밸런싱(축소·재조정)에만 적용, 그리드 신규매수는 잔여예산 규칙만 따름.
3. **골든 수치 출처(R8/G1)**: REQUIREMENTS §11-1 인용 수치는 basic_trade.md 유래. 값 자체는 v2 clip(0.8~4.0%) 내부라 유효 → 픽스처로 채택하되 테스트 주석에 출처 정정 표기.

## 결론(합의안)과 반영처

합의안은 [feature-strategy-engine.md](../features/feature-strategy-engine.md) §4·§5·§7·§12에 반영. 쟁점 상태:

- R1 워밍업 → min_history=270 거래일, 미충족 시 레짐 Neutral·E=0·주문표 `INSUFFICIENT_HISTORY` — `resolved` (feature §5)
- R2 σ_down 하한 0.03 적용, NaN은 배치 실패 처리 — `resolved` (feature §5)
- R3 전이 우선순위 ①Bear 진입 ②Bull 진입 ③이탈→Neutral(양방향 직행 대칭), 초기 상태 Neutral — `resolved` (feature §5)
- R4 전술 트랙 지표는 레버리지 자체 시계열 — `resolved` (feature §5, [ADR-006](../adr/006-ravg-v2-adoption.md) 영향 기재)
- R5 장중 트리거 → 조건부 지시문 강등 — `resolved` (feature §5)
- R6 수량: 균등 1/3·floor·호가 5원(매수 내림/매도 올림)·현금 버퍼 0.5%, 밴드는 리밸런싱 전용 — `resolved` (feature §5)
- R7 로트 FIFO 원장, 익절가 = 로트 체결단가×(1+체결일 Grid) 스냅샷, 코어 편입 기준가 = 전환일 종가×(1+전환일 Grid) — `resolved` (feature §5·§7)
- R8 지표 창 거래일 기준(정지일 봉 제외), KRX 캘린더는 pykrx 단일 소스, 정지 시 발주 보류 — `resolved` (feature §5)
- σ_down 하한·워밍업 값 등 수치는 백테스트로 재조정 대상 — `deferred(파라미터 튜닝 단계, Phase 4)` (feature §15)
- 골든 수치 출처 정정 — `resolved` (feature §12 주석)

**위험→테스트 추적**: SA-qa의 G1~G3, B1~B7, R1~R3, F1~F2 전 항목을 feature §12에 등재. ADR: [ADR-006](../adr/006-ravg-v2-adoption.md)(전략 채택), [ADR-005](../adr/005-strategy-single-source.md)(코드 단일 소스).
