# ADR-010 — 소량 진입 부트스트랩: 시작 후 10거래일, 목표 미달분의 15%를 종가 지정가로

- 상태: 채택 (2026-09-08, 사용자 지시 "검토된 내용대로 구현")
- 관련: [ADR-007](007-ravg-v25-adoption.md) 정본 v2.5 에 대한 개정 · [docs/fast-entry-study-20260908.md](../docs/fast-entry-study-20260908.md)(탐색 234개 조합·3 표본) · [docs/cold-start-entry-study-20260908.md](../docs/cold-start-entry-study-20260908.md)(문제 정의) · [feature-strategy-engine §5](../features/feature-strategy-engine.md)

## 배경

RAVG 의 매수는 그리드 지정가(종가 −1·2·3×Grid)만이라, 보유 0·현금만으로 시작하는 사용자는 첫 체결까지 중앙 10일(그리드 1단 하루 체결 확률 26%), 하락장 시작이면 규칙상 매수 정지로 중앙 78일을 기다린다. 사용자(2026-09-08): "오늘부터 시작했는데 매매 성공 확률이 25%면 너무 작다 — 상승·중립·하락장에 따라 작은 수량으로 일단 시작한 뒤 RAVG 2.5 가 적용되며 정상 상태로."

## 결정

> **보유 0(현금만)으로 시작한 포트에 한해**, 시작 후 10거래일 동안 K200 보유가 목표에 못 미치면 매일 미달분의 15%(하락장 7.5%)를 전일 종가 지정가로 추가 매수한다. 그날 그리드 3단 예산은 85%로 줄인다. 갭 필터 날은 내지 않는다. 11일째부터 RAVG v2.5 그대로. **보유분을 입력해 시작한 포트·전환 포트(시작 시점에 보유 있음)는 대상 외**(2026-09-08 사용자 지적 — "오늘부터 새로 시작, 보유 수량이 없을 때만").

| Params | 값 | 근거 |
|---|---|---|
| `boot_days` | 10 | 비용을 0 으로 만드는 경계 — N20 부터 250일 수익 차이 중앙 −0.26%p |
| `boot_frac` | 0.15 | 0.10 → 0.15 에서 진입 30% 빨라지고 비용 동일, 0.25 부터 −0.3%p |
| `boot_delta` | 0 (종가) | 하루 체결 확률 74% — 시장가보다 비용 낮고(Δ +0.1~0.15%p) "매일 매매가 일어난다" 충족 |
| `boot_bear_mult` | 0.5 | 하락장도 첫날 진입하되 목표(20%)의 절반 속도. 1.0 은 최악 −4.5%p 꼬리 |

효과(87개 시작 × 250일, 시작 시점 3 표본): 첫 체결 10일 → **1~2일**(90% ≤ 3일), 노출 50% 도달 15 → 7일, 5일 노출 0 → 32~47%. 250일 수익 차이 중앙 −0.09 ~ 0.00%p·평균 ≈ 0, 우세 38~44/87, MDD 불변. 최악 −2.9 ~ −4.6%p(시작 직후 급락 지속).

## 구현

- `strategy/params.py` 4개 변수(알고리즘 설정 '초기 진입' 그룹, 포트별 동결 변수에도 포함). `boot_frac 0` 또는 `boot_days 0` = 끔.
- `planner.plan(..., days_since_start)` — None 이면 적용 없음. 규칙: 미달분 × f 를 `round_tick(close×(1−δ·Grid))` 지정가 `boot` 주문으로(현금버퍼 반영 현금 안에서), 그리드 예산은 (1−f). 하락장은 그리드가 정지된 채 `boot` 만 f×0.5; 이때도 갭 필터 기준(`gap_cancel_exact`)을 낸다.
- `days_since_start` 정의 — **백테스트**: 첫 OK 계획일 = 0일째(엔진이 카운트, 절단 실행도 같은 값 → [ADR-005](005-strategy-single-source.md) 동일성 유지). **실전**(`signals._portfolio_orders`): 시작일 = max(포트 생성일, 첫 거래일) — 시작 패널이 입금을 직전 영업일로 소급 기록해도 생성일이 오늘을 잡아 준다; 시작일 **뒤** 봉 수. 거래가 없거나 **시작일까지 등록된 매수(보유분 입력·전환 시드)가 있으면 None**(콜드 스타트 아님). 백테스트도 `initial_lots` 로 시작하면 None. **모델 포트**(공용 KR 신호)는 9년째라 대상 밖.
- 09:01 실행기: `boot` 는 그리드와 함께 갭 필터 대상, 상한·매수가능 축소는 동일, 정렬상 가장 얕은 지정가라 먼저 발주. 화면: 종류 '초기 진입', 제목에 '초기 진입 n/10일', 계산 근거 설명.
- 검증(단계별): ① 플래너 단위 6종(창 안/밖·끔·수량/가격/그리드 축소·하락장 배수/갭 기준·목표 도달·현금 부족·엔진 카운트) ② **끔 = 변경 전 엔진과 KPI·최종 자산 비트 동일**(2017~2026 KODEX: total_return 2.454899, 345,489,906원) ③ 기본값의 전 구간 영향: 첫 10 활동일에만 boot, 최종 자산 +0.17%(346,063,150원), 거래 375 → 379, MDD −21.66 → −21.67% — 모델 포트의 현재 잔고가 조금 달라져 공용 신호의 그리드 수량도 소폭 달라진다(가격·레짐·E 는 동일) ④ 실전 경로: 오늘 시작 포트 → boot 줄·`boot {day:1, days:10}`·스냅샷 저장, 20거래일 뒤 포트 → 없음, 모델 신호 → 없음 ⑤ 실행기: 갭 출발이면 boot 도 생략, 아니면 종가 지정가가 먼저.

## 대안과 기각

- **시가 매수(부트스트랩 시장가)**: 같은 f 에서 종가 지정가보다 Δ −0.1~0.15%p. 기각.
- **큰 f(25~100%)·무기한**: 진입은 빠르지만 250일 수익 중앙 −0.3~−0.7%p, 최악 −6%p — 그리드의 저가 진입 우위 포기. 기각.
- **하락장 진입 없음(bear 0)**: 하락장 시작 사용자가 중앙 78일을 빈손으로 기다린다 — 사용자 요구("하락장도 소량") 와 어긋남. 기각.
- **하루 매수 상한을 진입 가속에 쓰기**: 상한은 첫 체결에 영향 없고 목표 도달 속도만 정한다(fast-entry §7). 사용자 결정으로 기본 0(참고용).

## 영향

- 정본 규칙 개정 3번째(ADR-006 → 007 → 010). 골든 값 변화 없음(플래너 테스트는 `days_since_start` 미지정 = 종전). 백테스트 결과는 첫 10 활동일만 달라지며 새 잡부터 적용(저장된 잡은 불변).
- 하루 매수 상한 기본값 20% → **0(없음)** 도 이 변경에 포함(2026-09-08 사용자: "참고용, 사용하지 않음").
- 버전: 새 동작(전략 개정) — 마이너 `0.12.0`.
