# ADR-005: 전략 코드 단일 소스 (백테스트 = 일일 시그널 엔진)

## 상태

Accepted

## 배경

REQUIREMENTS §8은 "백테스트 엔진과 일일 시그널 엔진은 동일한 전략 코드를 공유할 것"을 제약으로 명시한다. 검증된 로직이 그대로 운용에 쓰여야 백테스트 결과가 실전 주문표의 신뢰 근거가 된다.

## 선택지

1. 백테스트용(벡터화)과 시그널용(단일 시점) 별도 구현
2. 단일 전략 모듈 `strategy/` — 순수 함수 `(OHLCV 스냅샷, 파라미터, 전일 상태) → (레짐, E, 배분, 주문표)`를 양쪽이 호출

## 결정

2안. 백테스트는 이 함수를 일자 루프(또는 벡터화 래퍼)로 호출하고, 일일 배치는 최신 일자 1회 호출한다.
**수용 기준**: 과거 특정일 d에서 절단한 백테스트의 d일 주문표와 시그널 배치의 d일 주문표가 바이트 동일해야 한다(검토 로그 [R2 재현성](../discussion/review-strategy-engine-20260828.md)).
차트 표시용 지표(TS 클라이언트 구현)는 이 결정의 예외이며, 서버 수식과의 교차 검증 테스트를 의무화한다([검토 로그](../discussion/review-chart-20260828.md)).

## 이유

1안은 성능은 좋지만 두 구현의 미세한 차이(반올림·경계)가 조용히 벌어져 "검증된 전략이 운용된다"는 전제를 깬다. 성능은 벡터화 래퍼로 보완 가능.

## 영향

전략 모듈은 부작용 없는 순수 함수로 설계, 난수·현재시각 사용 금지. 골든 테스트가 이 모듈 하나만 대상으로 하면 된다.
