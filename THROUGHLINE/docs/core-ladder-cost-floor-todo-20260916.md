## 1. 관찰 (실계좌, 2026-09-16 주문표)

원격 계좌 pf 21 — 시작할 때 **보유분 400주(취득가 95,805)** 를 입력한 계좌. 이 400주는 체결 이력이 없어 `core` 로트고,
익절은 ADR-014 사다리 **종가 × (1 + k·Grid)**, k=1..3, 수량 50/30/20 으로 매일 다시 잡힌다.

| 주문표 | 기준 종가 | 1단 | 2단 | 3단 |
|---|---|---|---|---|
| 09-14 실행분 | 109,735 (09-11) | 112,480 · 200주 | 115,225 · 120주 | 117,970 · 80주 |
| 09-16 실행분 | 104,650 (09-15) | **107,270** · 200주 | 109,885 · 120주 | 112,500 · 80주 |

시장이 −4.6% 내려오는 동안 익절 목표도 그만큼 **따라 내려왔다**. 첫 +2.5% 반등에 200주가 나간다.
취득가 95,805 대비로는 여전히 +12.0 / +14.7 / +17.4% 여서 손실 매도는 아니지만, **취득가가 종가에 가까운(또는 위인) 계좌**에서는
같은 규칙이 "손실에 가까운 익절"을 만든다. v0.31.2 부터 익절 줄에 취득가 대비 손익이 표시되어 이 모습이 눈에 띈다.

이것은 **버그가 아니라 문서화된 근사**다 — ADR-014 §한계 "익절가가 여전히 오늘 종가 기준이라는 근사는 그대로다. 평단과의 관계는 별건",
entry-holding-tp-ladder-20260913 §8.3. 이 TODO 가 그 '별건'이다.

## 2. 이미 측정되어 기각된 대안 (다시 재지 않는다)

| 대안 | 결과 | 출처 |
|---|---|---|
| 평단 기준 익절 (취득가 × (1+Grid) 한 줄) | 평단 < 종가면 익절가가 이미 지나 있어 **즉시 전량 매도** | manual-holdings-tp-review-20260903 |
| 기준가 고정(P₀) 사다리 + 단별 잔여 유지 | 승률 32:31, 전량 매도 비중 55% — 현행(57%)과 차이 없음 | ADR-014 §검토했으나 채택하지 않은 것 |
| 익절 수량 상한 (목표 초과분만 / 50% / 절반 보유) | 중립~악화 | PR #244 (2026-09-14) |
| "목표 미달이면 팔지 않기" | **27:38, 최악 −8.4%p** | PR #244 |
| 촘촘한 사다리 (1·1.5·2×Grid) | +0.170%p, 39:18 — 현행 배치보다 못함 | ADR-014 |

마지막 두 줄이 이 TODO 의 **위험 신호**다: 취득가 하한은 시장이 취득가 아래에 오래 머물 때 "팔지 않기"와 같은 상태가 되므로,
같은 방식으로 나빠질 수 있다. 그래서 측정 없이는 넣지 않는다.

## 3. 검토할 후보 (측정 대상)

- **L0 현행** — `P_k = round_up(close × (1 + k·Grid))`
- **F1 하한** — `P_k = max(P_k, round_up(cost × (1 + Grid)))`; 단이 겹치면 수량 병합. 취득가 < 종가면 하한이 안 걸려 **현행과 동일**(pf 21 지금: 하한 98,200 < 107,270).
- **F2 앵커 시프트** — 기준가를 `max(close, cost)` 로 두고 사다리 전체를 올린다. F1 보다 강하다.

취득가는 `Lot.price`(로트별) — 보유분 입력·전환 시드 로트는 입력한 평단, 백테스트 `initial_lots` 는 시작 종가(또는 지정값).

## 4. 측정 방법 (기존 하네스 재사용)

`apps/api/scripts/entry_holding_tp_study.py` 의 구조 그대로 — 시작일 21거래일 간격 ~87~89개 × 각 1년, 보유 시작(현금 40% + K200 60%), core 익절만 교체, 짝 비교.
**하한이 실제로 걸리는 표본을 만들어야 한다**: 보유분 취득가를 시작 종가의 **+10% / 0% / −10%** 세 가지로 두고 각각 잰다
(현행 하네스는 시작 종가 취득이라 F1 이 L0 과 같아져 아무것도 재지 못한다).

보고 항목(ADR-014 표와 같게): 평균·중앙·최악 차이(%p), 이김:짐:동일, 전량(≥99%) 매도 비중, MDD. 노이즈 밴드는 validation-methodology-20260913.

**사전 등록 채택 기준** (측정 뒤에 바꾸지 않는다):
- 취득가 +10% 표본(하한이 걸리는 경우)에서 **이김 ≥ 짐**, 최악 차이 **−1.0%p 이내**, MDD 악화 없음
- 취득가 0% / −10% 표본에서 L0 과 **동일**(하한이 안 걸려야 정상 — 다르면 구현 오류)
- 위를 충족하지 못하면 **기각하고 이 문서에 기록**. 정본 §12 는 최대 수익이 아니라 위험 대비 효율이다.
