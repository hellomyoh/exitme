# 레버리지 전략:전술 비율 70:30 → 85:15 적용과 비교 분석 (2026-09-12)

사용자 지시("85:15 이거 적용해서 현재와 비교 분석해줘")로 `lev_strategic_ratio` 를 0.7 → **0.85** 로 바꾸고,
현행 대비 차이를 전 구간·연도별·레짐별·낙폭·창별·민감도로 측정했다.

- 권위: 정본 §10 튜닝표 `레버리지 트랙 비율 | 전략 70 : 전술 30 | ○`(튜닝 허용) 범위 내 **값 조정**이므로
  `grid_max` 4.0→2.5% 와 같은 절차 — 새 ADR 없이 [feature-strategy-engine](../features/feature-strategy-engine.md)
  §5.5·§15 가 확정값을 가진다. 정본(SOURCES)의 70:30 은 원본 보존 원칙으로 수정하지 않는다.
- 데이터: KIS 069500/122630 일봉, 워밍업 뒤 2018-01-25~2026-09-10(8.6년), 자본 1억, 엔진 v0.26.0 기준값.
- 비용: 수수료 0.015%·시장가 슬리피지 0.1%·레버리지 실현이익 15.4%·보유비용 대리치 연 0.15/0.64% 차감 후.
- 배경 연구: [vol-managed-review-and-three-proposals-20260912](vol-managed-review-and-three-proposals-20260912.md) §2.2.
- 모의 계산이며 미래 수익을 보증하지 않는다.

## 1. 무엇이 바뀌나

레버리지 예산 `w_LEV` 안의 배분만 바뀐다. 총 레버리지 목표(`w_LEV`)도, K200 목표(`w_200`)도, 레짐 규칙도 그대로다.

```
전략 트랙(상시 보유)  w_LEV × 0.70 → × 0.85
전술 트랙(눌림목 진입, EMA20 회귀 시 이탈)  w_LEV × 0.30 → × 0.15  (1·2차 각 절반)
```

전술 트랙은 조건을 만족할 때만 들어가고 회귀하면 나가므로, 비중을 줄이면 **평소 대기하던 현금이 상시 보유로 옮겨간다.**
그래서 변화는 **상승장에서만** 나타난다(중립·하락장은 레버리지 자체가 0).

## 3. 시작일 89개(한 달 간격, 1년 보유) 짝 비교

| 지표 | 값 |
|---|---|
| 수익률 차이 평균 | **+1.80%p** |
| 중앙값 | **+0.17%p** |
| 표준편차 | 3.78%p |
| 분위 (최악 / 10% / 25% / 75% / 90% / 최선) | −0.80% / −0.57% / −0.29% / +1.93% / +6.42% / **+19.01%** |
| 이김 / 짐 / 동일 | 49 / 33 / 7 |
| MDD 차이 평균 | −0.47%p (중앙 −0.39%p) |
| MDD 악화 창 / 개선 창 | **73 / 0** (최악 −1.53%p) |

**차이가 큰 창은 전부 2025년 시작**(+19.0 / +14.0 / +13.8 / +12.6 / +10.7%p)이고,
불리한 창은 2018년과 2024년(−0.60 ~ −0.80%p)이다.

이 표의 핵심은 비대칭이다. **수익 이득은 몇 개 창에 몰리고(중앙값 +0.17%p), 낙폭 비용은 거의 모든 창에 고르게
발생한다(73/89 악화, 개선 0).** 평균만 보면 좋아 보이지만 "보통의 해"에는 거의 차이가 없고 낙폭만 조금씩 깊다.

전반·후반을 나눠도 방향은 같다: 전반(2018-01~2022-05) +2.49%, 후반(2022-05~2026-09) +5.93% — 두 구간 모두 양수다.

| 비율 | 평균 | 중앙 | 최악 | 90%분위 | 이김 | MDD 평균차 | MDD 악화 창 | 수익/MDD 효율 |
|---|---|---|---|---|---|---|---|---|

단일 경로에서 0.75 의 MDD(−21.8%)가 현행보다 나아 보였지만 **짝 비교에서는 28개 창이 악화하고 개선은 0** 이다 —
단일 경로 MDD 차이는 잡음이었다.

**무릎점(knee)은 없다.** 비율을 올릴수록 수익도 낙폭도 단조롭게 커지고, 낙폭 1%p 당 얻는 수익(효율)은
7.5 → 5.3 → 3.8 → 3.1 로 단조 감소한다. 이건 최적화 문제가 아니라 **위험 선호 다이얼**이다.

### 4.1 0.80 → 0.85 증분만 보면

같은 89개 창에서 0.80 기준으로 0.85 를 비교하면:

- 수익 평균 **+0.27%p**, **중앙값 −0.03%p**, 최악 −0.97%p, 최선 +5.19%p, **이김 37/89**
- MDD 평균 **−0.18%p**, 악화 창 **34**, 개선 창 **0**

즉 마지막 한 칸(0.80 → 0.85)은 **보통의 창에서 약간 손해(중앙 −0.03%p, 89창 중 52창에서 열세)**이고,
강한 상승 창에서만 벌며, 낙폭은 34개 창에서 더 깊어진다. 이 구간의 교환비가 전체에서 가장 나쁘다.

## 5. 결론

1. **지시대로 0.85 를 적용했다.** 전 구간 CAGR +1.14%p, 최종 자산 +3,056만원, 대가는 MDD −0.80%p.
2. 이득의 성격은 **노출 증가**다. 샤프는 1.027 → 1.049 로 거의 그대로고, 수익은 2020·2025·2026 세 해에 몰린다.
   Moreira·Muir 의 결론과 같은 구조 — 노출을 키우면 수익이 커지지만 위험조정 성과가 그만큼 좋아지지는 않는다.
3. **비용은 고르고 이득은 몰린다.** MDD 는 89창 중 73창에서 나빠지고 개선된 창은 하나도 없다.
   반면 수익 중앙값은 +0.17%p 로, 절반의 해에는 사실상 차이를 못 느낀다.
4. **0.80 을 함께 검토할 값으로 남긴다.** 이득의 85%(평균 +1.53 vs +1.80%p)를 낙폭 비용 60%(−0.29 vs −0.47%p)로
   얻고, MDD 악화 창이 73 → 55 로 줄어든다. 0.80 → 0.85 증분은 중앙값이 음수라 전체 구간에서 가장 불리한 한 칸이다.
5. 전술 트랙은 0.15 로도 여전히 순손실(−53만원)이다. 완전히 없애는 1.00 은 CAGR +1.67%p·MDD −1.7%p 이고
   규칙 하나와 체결 21% 가 사라진다 — 더 공격적인 선택지로 기록만 해 둔다.
