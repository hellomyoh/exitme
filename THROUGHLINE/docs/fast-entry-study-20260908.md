# 소량 진입(부트스트랩) 알고리즘 탐색 — 콜드 스타트 첫 10거래일 (2026-09-08)

> 지시(사용자): "오늘부터 시작했는데 매매 성공 확률이 25%면 너무 작다. 상승·중립·하락장에 따라 작은 수량으로 매매를 일단 시작한 뒤 RAVG 2.5 가 적용되며 정상 상태로 가게. 진입 시점을 시뮬레이션으로 검증하고, 입력 변수를 바꿔 가며 최적 알고리즘을 찾아라. 하루 매수 상한 20% 는 유지." 선행: [cold-start-entry-study-20260908.md](cold-start-entry-study-20260908.md). 스크립트: 세션 스크래치 `sim_boot_sweep.py`.

## 1. 후보 규칙의 형태

보유 0(현금만)으로 시작한 포트에 **부트스트랩 매수 주문**을 하나 더 낸다:

> 노출 충족률(K200 보유 / 목표) < θ 이고 시작 후 N 거래일 이내이면, 매일 **미달분(목표 − 보유)의 f** 를 **전일 종가 × (1 − δ·Grid) 지정가**(또는 시장가)로 추가 매수. 하락장은 f × bear. 그리드 3단은 (1 − f) 배로 축소해 예산 중복을 막고, 갭 필터 날은 부트스트랩도 생략. 하루 매수 상한 20% 는 그대로 적용.

RAVG 자체는 건드리지 않는다 — 부트스트랩은 콜드 스타트 구간에서 잔여 예산의 일부를 "체결 확률 높은 가격"으로 앞당겨 넣는 규칙이고, N 일이 지나거나 목표에 닿으면 사라진다.

**지정가 깊이별 하루 체결 확률(실측 2,072일, KODEX 200):**

| 지정가 | 체결 확률 |
|---|---:|
| 종가 (δ 0) | **74%** |
| 종가 − 0.25·Grid | 61% |
| 종가 − 0.5·Grid | 46% |
| 종가 − 1.0·Grid (= 그리드 1단) | 26% |

→ "25%" 는 그리드 1단의 확률이다. 종가 지정가는 4일 중 3일 체결된다.

## 2. 조건

- 자료·표본: cold-start 연구와 동일 — 2017~2026 KODEX 200/레버리지, 시작 87개(21거래일 간격, BULL 39 · NEUTRAL 8 · BEAR 40), 250거래일 추적, 자본 1억, 시작 시점 레짐은 전 구간 백테스트 경로.
- 비교 기준: **같은 시작 시점 쌍**의 250일 수익률 차이(Δ = 후보 − 현행). 진입 속도: 첫 체결 일수, 노출 50%·90% 도달 일수, 5일·20일 시점 노출 충족률.
- 탐색: 1단계 72개(θ {0.5, 0.8} × f {0.10, 0.25, 0.5, 1.0} × {시장가, 종가 지정가, −0.5·Grid 지정가} × bear {0, 0.5, 1.0}), 2단계 162개(θ {0.5, 1.0} × f {0.05, 0.10, 0.15} × δ {0, 0.25, 0.5} × bear {0.25, 0.5, 1.0} × N {∞, 10, 20}), 3단계 견고성(시작 시점을 +7·+14 거래일 옮긴 표본 2개에서 상위 후보 재평가).

## 3. 결과

### 3.1 현행(그리드만, 상한 20%)

첫 체결 중앙 10일(90% 169일 — 하락장 시작), 5일 내 미체결 56/87, 노출 50% 15일 · 90% 39일, 5일 노출 0% · 20일 61%. 레짐별 첫 체결: BULL 4일 · NEUTRAL 2.5일 · BEAR 78일.

### 3.2 1단계 — 크기 f 가 크면 빠르지만 비싸다

| f (매일 미달분의) | 첫 체결 중앙 | Δ 중앙 (범위) | 평균 Δ |
|---|---:|---|---|
| 0.10 | 1~3일 | −0.16 ~ −0.35%p | −0.2 ~ +0.05 |
| 0.25 | 1~3일 | −0.29 ~ −0.74%p | −0.3 ~ +0.3 |
| 0.50 / 1.00 | 1~3일 | −0.38 ~ −0.72%p | −0.3 ~ +0.5 |

큰 f 는 중앙값이 나쁘고 평균이 좋은 **비대칭**(대부분 시작에서 조금 잃고, 하락장 뒤 급반등 시작에서 크게 얻음, 최악 −6%p). "떨어질 때 산다"는 그리드의 진입 우위를 시가·종가 매수가 포기하기 때문. 시장가보다 종가 지정가가 일관되게 낫다(같은 f 에서 Δ 중앙 +0.1~0.15%p).

### 3.3 2단계 — 기간 N 을 두면 비용이 사라진다

N 을 10거래일로 제한하면 Δ 중앙이 −0.05%p 안으로 들어오고 평균은 0 근처, 우세 비율 39~40/87 로 현행과 대등해진다(진입 속도는 유지). 상위 후보:

| 규칙 (θ1.0, 종가 지정가) | 첫 체결 중앙/90% | 5일 내 미체결 | 노출 50% / 90% | 5일 / 20일 노출 | Δ 중앙 / 평균 / 최악 | 우세 |
|---|---|---:|---|---|---|---:|
| f0.10 · bear×0.5 · N10 | 1 / 3일 | 0 | 10 / 32일 | 22% / 66% | −0.05 / −0.01 / −2.15%p | 39/87 |
| f0.15 · bear×0.25 · N10 | 1 / 3일 | 0 | 7 / 32일 | 25% / 69% | −0.04 / +0.04 / −2.86%p | 39/87 |
| **f0.15 · bear×0.5 · N10** | **1 / 3일** | **0** | **7 / 32일** | **32% / 69%** | **−0.06 / −0.02 / −2.87%p** | **39/87** |
| f0.15 · bear×1.0 · N10 | 1 / 3일 | 0 | 5 / 32일 | 49% / 78% | −0.10 / −0.10 / −4.48%p | 38/87 |
| f0.15 · bear×0.5 · N20 | 1 / 3일 | 0 | 8 / 32일 | 32% / 82% | −0.26 / −0.13 / −3.89%p | 38/87 |
| f0.15 · bear×0.5 · N∞ | 1 / 3일 | 0 | 8 / 31일 | 32% / 82% | −0.43 / −0.14 / −6.05%p | 33/87 |
| f0.15 · δ0.25 · bear×1.0 · N20 | 2 / 3일 | 1 | 6 / **23일** | 46% / 87% | −0.18 / −0.19 / −5.01%p | 38/87 |

노출 90% 도달이 32일에 묶이는 것은 **상한 20%**(사용자 유지 결정) 때문이다 — 상한이 없으면 30일.

### 3.4 3단계 — 시작 시점을 옮겨도 같은가

| 표본 | 현행 첫 체결 / 5일 노출 | f0.15·bear×0.5·N10 | f0.10·bear×0.25·N10 | f0.15·bear×1.0·N10 |
|---|---|---|---|---|
| 기본(+0) | 10일 / 0% | 1일 · 5일 32% · Δ −0.06 / −0.02 | 1일 · 17% · Δ −0.02 / +0.04 | 1일 · 49% · Δ −0.10 / −0.10 |
| +7 거래일 | 10일 / 0% | 1일 · 34% · Δ +0.00 / −0.01 | 1일 · 32% · Δ −0.00 / +0.01 | 1일 · 52% · Δ +0.00 / −0.07 |
| +14 거래일 | 8.5일 / 27% | 2일 · 47% · Δ −0.09 / −0.03 | 2일 · 41% · Δ −0.05 / +0.02 | 2일 · 52% · Δ −0.07 / −0.09 |

(Δ = 중앙 / 평균, %p). 세 표본에서 N10 계열은 모두 Δ 중앙 |0.1|%p 이내·평균 ≈ 0, 우세 38~44/87 — 특정 시작 시점에 맞춘 결과가 아니다.

## 4. 채택 후보 — "첫 10거래일 소량 진입"

> **시작 후 10거래일 동안, K200 보유가 목표에 못 미치면 매일 미달분의 15%(하락장 7.5%)를 전일 종가 지정가로 추가 매수한다. 그 날의 그리드 3단은 85%로 축소한다. 갭 필터 날은 내지 않는다. 11일째부터는 RAVG v2.5 그대로.**

- 효과(3 표본): 첫 체결 **1~2일**(90% ≤ 3일, 5일 내 미체결 0), 5일 노출 32~47%, 20일 68~70%, 노출 50% 도달 6~7일(현행 15일). 하락장 시작도 첫날 소량 진입(현행 78일 대기).
- 비용: 250일 수익률 차이 중앙 −0.09 ~ 0.00%p, 평균 −0.03 ~ −0.01%p, 최악 −2.9 ~ −4.6%p(하락 지속 구간), 우세 38~44/87. MDD 중앙 불변(−10.7%).
- 왜 이 값인가: f 는 0.10 → 0.15 에서 진입이 30% 빨라지고 비용은 같다(0.25 부터 비용 발생). δ 0 은 체결 확률 74% 로 "매일 매매가 일어난다"는 요구를 충족하면서 시장가보다 비용이 낮다. bear 0.5 는 하락장에서도 첫날 진입하되 목표(20%)의 절반 속도로 — 1.0 은 최악 −4.5%p 로 꼬리가 길어진다. N10 은 비용을 0 으로 만드는 경계(N20 부터 Δ 중앙 −0.26).

## 5. 구현 설계 (승인 시 ADR-010)

- `Params`: `boot_days=10`, `boot_frac=0.15`, `boot_delta=0.0`, `boot_bear_mult=0.5` (0 = 끔). 정본 개정으로 [ADR-007](../adr/007-ravg-v25-adoption.md) 뒤 ADR-010.
- `planner.plan(..., days_since_start: int | None)` — None 이면 부트스트랩 없음. 백테스트 엔진은 첫 OK 계획일부터 카운트, 실전 `_portfolio_orders` 는 포트 첫 거래(입금) 이후 거래일 수. 모델 포트(9년 운용)는 대상 밖 → ADR-005 의 "백테스트 절단 = 시그널" 동일성은 같은 `days_since_start` 를 넘기므로 유지.
- 주문 종류 `boot`(지정가 매수). 09:01 실행기: 갭 필터를 `grid*` 와 `boot` 에 적용, 상한 순서는 시장가 → 얕은 지정가(종가 지정가가 가장 얕으므로 boot 가 먼저). 화면 라벨 "초기 진입". 상태 줄: 부트스트랩 구간이면 "초기 진입 중 (n/10일)".
- 테스트: 골든 테스트는 백테스트 첫 10일이 바뀌므로 기대값 갱신(사유 기록), 부트스트랩 단위 테스트(첫날 주문·그리드 축소·하락장 배수·10일 종료·목표 도달 종료·갭 필터 생략), 실행기 테스트에 boot 줄 1건.
