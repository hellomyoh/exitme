# 01. 젠포트 (GenPort, 뉴지스탁) — 조사일 2026-09-05

- 공식: https://genport.newsystock.com/
- 분류: 국내 퀀트 백테스트 + 증권사 연동 자동매매(예약매매) 플랫폼
- 조회 경로: 공식 메인(직접), 키움증권 로보마켓 젠포트 FAQ(제휴 1차 자료), 젠포트 매뉴얼(wikidocs, 공식 문서)

## 1. 서비스 개요

개인 투자자용 "투자형 로보어드바이저" 플랫폼. **백테스팅 엔진 + 전략 마켓(젠마켓) + 실전 연동
(젠트레이더)** 3층 구조로, 사용자가 만든 전략을 검증한 뒤 증권사 계좌에 연결해 자동 발주까지
이어지게 하는 것이 핵심 가치 제안이다.

## 2. 기능별 정리

### 2.1 전략 수립 (노코드 조건 선택형)
- 전략 유형 3종: **트레이딩**(단기·중기), **자산배분**(중장기), **다이렉트 인덱싱**(테마·업종·지수
  맞춤 포트폴리오).
- 트레이딩 전략 입력 요소: 투자 자금 규모, 보유 기간(1일~6개월), 투자 종목 수,
  투자 우선순위(수급/추세/성장/자산배분/가치/ETF).
- 자산배분 전략 추가 요소: 최적화 방법(**절대모멘텀 / 리스크패리티 / 최소분산 / 최대다각화**),
  리밸런싱 주기(3~12개월).
- 코딩 없이 조건을 조합하는 방식(사용자 정의 수식 지원 여부는 로그인 영역이라 미확인).

### 2.2 백테스트
- 일봉 백테스팅이 기본이며, **틱데이터 백테스팅**이 별도 상품으로 존재(패키지 판매).
- 무료 사용자에게 **백테스트 20회** 제공(공식 메인 표기).
- 포트 타입별 "동시 백테스트 가능 개수" 제한이 존재(구체 수치는 로그인 영역).

### 2.3 실전매매(자동 발주) — ExitMe 와 가장 크게 다른 지점
- **젠트레이더**에서 전략과 증권사 계좌를 연동하면 주문이 자동 실행된다(1포트-1계좌).
- 지원 증권사: **키움증권, 하이투자증권**(국내), **NH투자증권**(미국주식 주문연동은 NH 경유만 가능).
- 동시 운용 포트 수 제한: 기본 3개, 이용권으로 **최대 25개**까지 확장. 증권사별 상한이 별도로 있어
  키움 5 / 하이 10 / NH 25.
- 이용 자격 제한(키움 FAQ 명시): **주식예탁자산 200만원 미만이거나 직전 3개월 내 주식거래가 없으면
  서비스 이용이 제한될 수 있음.**

### 2.4 전략 마켓(젠마켓)
- 다른 사용자가 만든 전략을 공유·판매하는 마켓이 존재하며 **유료 알고리즘** 카테고리가 있다
  (매뉴얼에 "유료 알고리즘" 항목 존재). 창작자 수익 배분 구조로 추정되나 배분율은 미확인.

## 3. 유료화 모델

| 수익원 | 내용 | 확인 수준 |
|---|---|---|
| 이용권(구독) 판매 | 포트 저장 수 확장(기본 3 → 최대 25), 백테스트 관련 상품, 일봉+틱데이터 패키지 상품 | 구조 확인 / **가격 미확인(로그인 필요)** |
| 유료 알고리즘 마켓 | 타 사용자 전략 구매 | 존재 확인 / 가격·수수료율 미확인 |
| 증권사 제휴(간접) | 젠포트 가입 후 키움 매매 시 **수수료율 0.1% 적용** — 플랫폼이 증권사 고객 유치 채널로 기능 | 키움 FAQ 명시 |
| 무료 티어 | 백테스트 20회, 기본 포트 3개 | 공식 메인 명시 |

> 가격 표(원 단위)는 `Payment/Product.aspx` 가 로그인 리다이렉트되어 **본 조사에서 확인하지 못함**.
> 추정치를 적지 않는다(조사 규칙 2).

## 4. ExitMe 와의 비교

| 축 | 젠포트 | ExitMe |
|---|---|---|
| 전략 정의 | 조건 선택형(노코드) + 마켓에서 구매 | 정본 전략 1종(RAVG v2.5) 고정 + 변수 조정 |
| 백테스트 | 범용(종목 유니버스 스크리닝 중심), 무료 20회 제한 | 특정 페어(코스피200 ETF+레버리지) 전용, 무제한 |
| 발주 | **증권사 API 자동 발주** | 주문표 생성까지, 발주는 사용자가 HTS 에서 수동 |
| 실전 성과 | 연동 계좌 기준 자동 집계 | 사용자가 체결 등록 → TWR/XIRR·일지 |
| 공식 격리 | 포트별 전략 = 마켓/사용자 전략 | 포트별 파라미터 동결(전환 시 스냅샷) |
| 과금 | 이용권·마켓·증권사 제휴 | 없음(개인용) |

## 5. 시사점 (ExitMe 관점)

1. **자동 발주 유무가 시장의 주요 분기선**이다. 젠포트는 증권사 제휴로 이를 해결했고, 그 대가로
   증권사 종속(지원 증권사 3곳, 미국은 NH 전용)과 자격 제한(예탁자산 200만원)이 생겼다.
   ExitMe 의 "주문표 + 수동 발주"는 종속이 없는 대신 실행 이행률이 사용자에게 달려 있다 —
   현재 구조에서 계획 vs 체결 대조(일지)를 강점으로 유지하는 것이 합리적.
2. **무료 백테스트 횟수 제한(20회)** 이 국내 상용 서비스의 전형적 과금 트리거다. ExitMe 는 무제한
   실행이 가능한 구조라, 만약 공개 서비스화한다면 잡 큐·데이터 비용이 병목이 된다.
3. **포트 개수를 과금 단위로 삼는 모델**(3 → 25)은 ExitMe 의 다포트·공식 동결 구조와 직접 대응된다.
4. 전략 마켓은 사용자 생성 콘텐츠로 록인을 만드는 장치 — ExitMe 는 단일 정본 전략이라 대응물이 없다.

## 6. 미확인·후속 조사 항목

- 이용권 가격표(원), 백테스트 무제한 여부, 틱데이터 패키지 가격 → 계정 로그인 필요.
- 젠마켓 유료 알고리즘의 수수료 배분율.
- 자동매매 슬리피지·체결 정책(시장가/지정가 처리) 문서.
