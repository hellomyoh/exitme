# 06. Portfolio Visualizer — 조사일 2026-09-05

- 공식: https://www.portfoliovisualizer.com/ (요금 /pricing)
- 분류: 해외 **자산배분·포트폴리오 분석 도구**(백테스트·최적화·팩터 회귀·몬테카를로)
- 조회 경로: 공식 요금 페이지(직접)

## 1. 서비스 개요

개별 매매 신호가 아니라 **포트폴리오 수준의 분석**에 특화된 웹 도구. 자산배분 백테스트, 효율적 투자선
최적화, 팩터(파마-프렌치) 회귀, 몬테카를로 시뮬레이션, 전술적 자산배분 모델 등을 브라우저에서 실행한다.
개인 투자자뿐 아니라 RIA(투자자문)들이 리포트 작성에 쓰는 도구로도 알려져 있다.

## 2. 기능별 정리

| 기능 | 내용 |
|---|---|
| 포트폴리오 백테스트 | 자산 목록·비중·리밸런싱 규칙을 넣고 과거 성과 계산 (무료 15자산 / 유료 150자산) |
| 전술적 배분 모델 | 듀얼모멘텀 등 사전 정의 모델 실행. **유료 플랜에서 거래 신호(trading signals)와 YTD 반영** |
| 팩터 회귀분석 | 수익률을 팩터로 분해 |
| 자산 분석 | 상관·리스크 지표 등 |
| 최적화·시뮬레이션 | 최적화·몬테카를로 결과 저장 |
| 리포트 | 커스텀 PDF 리포트 |
| 협업 | 팀 멤버 동기화(유료) |

## 3. 유료화 모델 — "분석 규모·상업적 사용" 과금

| 플랜 | 가격(USD, 연간 청구 기준) | 용도 | 핵심 제한 |
|---|---|---|---|
| Free | $0 | 개인·교육 | 백테스트 **최대 15자산**, 히스토리 제한, YTD 제외, 팀 동기화 불가 |
| Basic | **$30/월** | 개인·교육 | 최대 150자산, YTD 포함, 포트폴리오 저장 50개 |
| Pro | **$55/월** | 개인 + **상업적 사용 허용** | 최대 150자산, 저장 150개 |

특징: 기능 자체(팩터 회귀·최적화·PDF)는 무료에도 열려 있고, **분석 규모(자산 수·저장 수)와
데이터 최신성(YTD), 그리고 상업적 사용권**으로 등급을 나눈다. "라이선스(상업적 사용)"를 가격 축으로
쓰는 점이 앞의 서비스들과 다른 점.

## 4. ExitMe 와의 비교

| 축 | Portfolio Visualizer | ExitMe |
|---|---|---|
| 분석 단위 | 자산배분·포트폴리오 통계 | 일별 매매 규칙 시뮬레이션 |
| 실행 | 없음(분석 전용, 신호 표시까지) | 주문표 생성 → 수동 발주 → 체결 기록 |
| 데이터 | 미국 중심 광범위 자산 | KIS 기반 KR/US 소수 종목 |
| 산출물 | PDF 리포트·통계 | 주문표·일지·대시보드 |
| 과금 | 규모·상업적 사용 기준 구독 | 없음 |

## 5. 시사점

1. **"실행 없는 분석 도구"도 유료 시장이 성립**한다 — 다만 가격 축이 실행이 아니라 *규모·라이선스·
   최신성*이다. ExitMe 의 시뮬레이터만 떼어 본다면 이 카테고리에 해당한다.
2. **YTD(최신 데이터)를 유료 경계로 두는 방식**은 데이터 신선도 자체를 상품화한 사례다. ExitMe 는
   자체 적재라 같은 축을 쓸 수 있으나, 개인 사용 목적상 실익은 낮다.
3. 상업적 사용(자문사 리포트)을 별도 등급으로 파는 모델은 B2B 확장 시 참고 가치가 있다.

## 6. 미확인·후속 조사 항목

- 월 결제(비연간) 정가 및 무료 티어의 정확한 히스토리 제한 연수.
- 데이터 소스·리밸런싱/배당 처리 규약 문서.
