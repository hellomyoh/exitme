# 10. 자동매매 인프라 — Alpaca / 한국투자증권 KIS Open API — 조사일 2026-09-05

- 공식: https://alpaca.markets/ · https://apiportal.koreainvestment.com/intro
- 분류: **브로커 API**(플랫폼이 아니라 인프라) — "자동 발주"를 하려면 결국 이 계층이 필요
- 조회 경로: Alpaca 공식 요금 페이지(직접), KIS 는 공식 포털·공식 GitHub·개발 사례(2차)

## 1. 왜 이 카테고리를 조사했나

앞선 서비스들(젠포트·Composer·QuantConnect)의 유료 기능 핵심이 전부 **자동 발주**였다. ExitMe 가
그 경계선을 넘을지 판단하려면 실행 계층의 제약·비용을 알아야 한다.

## 2. Alpaca (미국)

| 항목 | 내용 |
|---|---|
| Trading API | 알고리즘 주문 실행용 REST/스트리밍 API |
| Market Data API | 미국 주식·크립토 실시간/과거 데이터 |
| Broker API | 서드파티가 자체 증권 서비스를 얹는 엔드투엔드 계층 |
| 페이퍼 트레이딩 | **지원**(실계좌·실자금 불필요) — 전략 검증에 표준적으로 쓰임 |
| 거래 수수료 | 리테일 고객 **커미션 프리**. 단 일부 파트너 경유 계정·Elite Smart Router 는 수수료 발생 가능 |
| 데이터 요금 | 공식 요금 페이지 본문에서 **구체 가격 미표기**(별도 문서 필요) — 통상 무료 티어(IEX 등)와 유료 실시간(SIP) 구분 구조 |

- 시사점: 미국 시장은 **커미션 0 + API 무료 접근**이 기본값이라 자동매매 진입장벽이 매우 낮다.
  Composer 같은 서비스가 구독료만으로 성립하는 배경.

## 3. 한국투자증권 KIS Open API (한국) — ExitMe 가 이미 데이터로 사용 중

| 항목 | 내용 |
|---|---|
| 제공 범위 | **시세 수신 + 주문 송신 + 잔고 조회** — 즉 자동 발주까지 공식 지원 |
| 인증 | App key/secret → **접근 토큰 발급**(ExitMe 가 현재 쓰는 방식) |
| 모의투자 | 모의투자 환경(vps) 제공 — 실거래 전 검증 가능 |
| 호출 제한 | **초당 20건** 제한(개발 사례에서 반복 확인되는 실무 제약) |
| 국내 시장 커버 | 국내 주식·해외 주식 모두 TR 제공(ExitMe 는 국내 일봉·해외 일봉 수집에 사용 중) |
| 비용 | 계좌 보유자 대상 무료 이용이 일반적(공식 포털 기준). **별도 유료 플랜 확인되지 않음** |

- 시사점: **ExitMe 는 이미 자동 발주가 가능한 API 를 데이터 용도로만 쓰고 있다.** 즉 자동매매로의
  확장은 "새 파트너십"이 아니라 "주문 TR 사용 + 위험 통제 설계"의 문제다.

## 4. ExitMe 관점의 자동 발주 판단 재료

**가능성**: KIS API 가 주문을 지원하므로 기술적으로는 구현 가능(모의투자로 안전 검증 경로도 존재).

**하지만 현행 설계를 바꿀 때 생기는 부담**:
1. **책임 경계** — 지금은 "주문표 제시 → 사용자가 발주"라 오작동의 최종 방어선이 사람이다. 자동
   발주는 코드 결함이 곧 실주문 사고가 된다(본 프로젝트에서 이미 겪은 계획 덮어쓰기·토큰 만료·
   워커 미갱신 같은 사건이 실주문과 만나면 손실로 직결).
2. **상시 구동 원가** — QuantConnect 가 "라이브 노드"를 따로 파는 이유와 동일하게, 장중 상시
   프로세스·감시·알림이 필요해진다.
3. **규제·자격** — 국내 자동매매 서비스들이 예탁자산 하한(젠포트 200만원) 등 제한을 두는 배경.

**권고(현 시점)**: 자동 발주는 도입하지 않고, 대신 **실행 이행률을 높이는 보조 기능**(주문표 알림,
체결 등록 간소화, 계획 대비 미이행 경고)이 비용 대비 효과가 크다. 이는 경쟁 서비스들이 자동화로 해결한
문제를 ExitMe 의 구조(사람이 발주)를 유지한 채 완화하는 접근이다.

## 5. 미확인·후속 조사 항목

- Alpaca 시장 데이터 유료 플랜 가격표(공식 문서 별도 페이지).
- KIS 주문 TR 의 개인 사용 약관·초당 제한 외 일일 한도, 모의투자 계좌 발급 조건.
