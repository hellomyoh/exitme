# 05. Composer (composer.trade) — 조사일 2026-09-05

- 공식: https://www.composer.trade/ (요금 https://www.composer.trade/pricing)
- 분류: 해외 **노코드 알고리즘 투자 플랫폼 + 자체 증권(브로커)** — 전략 작성부터 자동 리밸런싱 실행까지
- 조회 경로: 공식 요금 페이지(직접), 보조로 리뷰 자료

## 1. 서비스 개요

"심포니(symphony)"라 부르는 시각적 전략(조건 분기 트리)을 노코드로 만들고, 백테스트한 뒤,
**Composer 자체 증권 계좌에서 자동 매매·리밸런싱**까지 수행한다. ExitMe 와 가장 유사한 사용자 여정을
가진 서비스이며(전략 → 검증 → 실전), 결정적 차이는 **실행 자동화와 브로커 내재화**다.

## 2. 기능별 정리

| 기능 | 내용 |
|---|---|
| 전략 작성 | 노코드 비주얼 에디터(조건 분기), **AI 로 아이디어 생성·평가** 기능 제공 |
| 백테스트 | 유료 플랜에서 **무제한 백테스트**, 속도가 강점으로 평가됨 |
| 자동 실행 | 전략을 계좌에 연결해 **자동 투자·리밸런싱** (핵심 유료 기능) |
| 계좌 | 자체 브로커리지 — 개인 과세계좌 및 **IRA(Roth/Traditional/Rollover)** 개설 지원 |
| 커뮤니티 | 공유 전략 마켓(수천 개 규모의 커뮤니티 전략) |
| 분석 | 포트폴리오 분석 지표, 전략 심화 인사이트 |
| API | 주식·ETF 거래 데이터 조회 API(무료 티어에도 언급됨), 비즈니스 플랜에 API 포함 |
| 제한 | 옵션·크립토·해외(비미국) 주식 미지원으로 평가됨(2차 자료) |

## 3. 유료화 모델 — "무료 설계 / 유료 실행" 이분법

| 플랜 | 가격 | 포함 |
|---|---|---|
| Build and Backtest | **무료** | AI 아이디어 생성·평가, 노코드 전략 구축·백테스트, 저장·관찰·공유, 데이터 API |
| Trading Pass (개인) | **연 결제 $384/년 = $32/월** (공식 표기) · 월 결제가는 공식 페이지 **미표시** | 자동 전략 투자, 무제한 백테스트, 포트폴리오 분석, IRA 계좌, **14일 무료 체험** |
| Business Account | 별도 문의 | 다중 자산 포트폴리오, 실시간 데이터 관리, API, 우선 지원 |

- 수수료: **주식 거래 커미션·운용 보수 없음**을 표방(2차 자료), 다만 FINRA·SEC 규제 수수료는 매도 시 부과.
- 경제성 평가(2차 자료): 월 $32~40 구독을 정당화하려면 최소 **$10,000 내외 투자금**이 필요하다는 지적.

> 표기 검증(재확인 2026-09-05): 공식 페이지는 **"$32/mo — Billed annually ($384/yr)"** 와
> "Yearly Save 20%" 만 노출하고 **월 결제 정가는 표시하지 않는다**. 20% 할인 표기를 역산하면
> 월 결제 $40 ($32 ÷ 0.8)이 되고 이는 2차 자료의 "$40/월"과 일치한다 — 다만 공식 확인은 아니므로
> **월 결제 $40 은 추정으로 표기**한다.

## 4. ExitMe 와의 비교

| 축 | Composer | ExitMe |
|---|---|---|
| 전략 정의 | 노코드 분기 트리, AI 생성 지원 | 정본 전략 고정 + 파라미터 동결 |
| 백테스트 | 무료 티어에서도 가능 | 무제한 |
| 실행 | **자체 브로커 자동매매**(구독의 본체) | 주문표 → 사용자 수동 발주 |
| 자산 | 미국 주식·ETF | 코스피200 ETF·레버리지 / QQQ |
| AI | 전략 아이디어 생성·평가 | 계좌 데이터 조회 챗봇(권한별 제한) |
| 과금 | 실행 구독(월 $32~40) | 없음 |

## 5. 시사점

1. **"설계·검증은 무료, 자동 실행은 구독"** 이 가장 선명한 가격 분할 사례다. 앞서 본 젠포트·
   QuantConnect 와 동일한 경계선이며, ExitMe 가 유료화한다면 같은 지점이 후보가 된다.
2. 브로커를 내재화하면 커미션 없이도 구독료로 수익화가 가능하다(주문 흐름·이자 수익 등 부가 수익 구조).
   ExitMe 처럼 증권사 연동이 없는 제품은 이 경로를 쓸 수 없다.
3. **AI 를 "전략 생성"에 쓰는 접근**은 ExitMe 의 "AI = 내 계좌 해설자"와 다르다. 후자는 규칙 신뢰성을
   해치지 않으면서 이해를 돕는 안전한 위치이며, 권한별 공개 제한과도 잘 맞는다.
4. 구독 대비 최소 투자금 논쟁($10k)은, 소액 사용자에게 구독형이 잘 안 팔린다는 신호 — 개인용
   무료(현 ExitMe)나 저가 티어가 필요한 이유.

## 6. 미확인·후속 조사 항목

- 월 결제 정가 1차 확인($40 여부), 비즈니스 플랜 가격.
- 자동 리밸런싱 체결 방식(시장가/장중 시점)과 슬리피지 공시.
