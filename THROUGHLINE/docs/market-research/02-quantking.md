# 02. 퀀트킹 (Quant King) — 조사일 2026-09-05

- 공식: https://quantking.net/ (구 도메인 quantking.co.kr — 현재 매물/차단 상태로 확인)
- 분류: 국내 퀀트 **종목 스크리닝 + 재무 데이터** 제공 프로그램 (설치형 + 모바일 앱)
- 조회 경로: 공식 사이트(내용 대부분이 스크립트 렌더라 텍스트 추출 실패), 앱 스토어/APK 설명,
  사용자 리뷰 블로그 — **1차 출처 확보가 제한적이며 아래 내용은 2차 자료 비중이 높다.**

## 1. 서비스 개요

"한국 퀀트 프로그램 1위"를 표방하는 재무 데이터 기반 종목 선정 도구. ExitMe·젠포트처럼 전략을
시계열로 백테스트하는 엔진이 중심이 아니라, **재무 지표로 종목을 걸러내고(스크리닝) 그 결과 포트폴리오를
제공**하는 데이터 서비스에 가깝다. 사용자는 프로그램을 내려받아 DART·증권사 HTS 와 병행 사용한다.

## 2. 기능별 정리 (확인된 범위)

| 기능 | 내용 | 확인 수준 |
|---|---|---|
| 재무 데이터 조회 | 최신 재무 지표·데이터 확인, **10년 재무 차트** | 앱 설명 |
| 종목 스크리닝 | 회원 전용 "로직 파일"로 조건에 맞는 종목 추출 | 2차 자료 |
| 퀀트 포트폴리오 | **5대 퀀트 포트폴리오** 제공(자체 산출 포트) | 앱 설명 |
| 컨센서스 데이터 | 애널리스트 컨센서스를 **엑셀 형식**으로 제공 | 앱 설명 |
| 백테스트 | 시계열 전략 백테스트 엔진 여부 **미확인** (스크리닝 결과의 과거 수익률 제시 형태로 보임) | 미확인 |
| 자동매매 | 없음(주문 연동 기능 확인되지 않음) | 미확인 |

## 3. 유료화 모델

| 수익원 | 내용 | 확인 수준 |
|---|---|---|
| 연 회원제 | **연 110,000원** 수준의 유료 회원(로직 파일·자체 포트폴리오 접근) | 2차 자료(리뷰) |
| 무료 범위 | 일반 조회는 무료, 특정 로직 파일·자체 포트폴리오는 유료 | 2차 자료 |

> 주의: 공식 요금 페이지를 직접 확인하지 못했다. 위 금액은 리뷰 자료 기준이며 현재 가격과 다를 수 있다.

## 4. ExitMe 와의 비교

| 축 | 퀀트킹 | ExitMe |
|---|---|---|
| 핵심 가치 | **데이터·스크리닝**(무엇을 살까) | **운용 규칙**(언제 얼마나 사고팔까) |
| 대상 자산 | 개별 종목(재무 기반) | 지수 ETF·레버리지 (재무 무관) |
| 백테스트 | 불명확 | 자체 엔진(일봉, 비용·세금 반영) |
| 실행 지원 | 없음 | 주문표·체결 등록·일지 |
| 과금 | 연 회원제(약 11만원) | 없음 |

## 5. 시사점

1. 국내 개인 퀀트 시장은 **"종목 선정 데이터"** 와 **"전략 운용 엔진"** 이 서로 다른 제품군으로
   갈라져 있다. ExitMe 는 후자에 속하며 전자와는 직접 경쟁하지 않는다(오히려 보완재).
2. **연 10만원대 회원제**가 국내 개인 대상 데이터 서비스의 가격 앵커로 보인다(퀀터스 1년 최저가와도
   같은 대역).
3. 설치형 프로그램 + 엑셀 산출물이라는 형태가 여전히 통용된다는 점은, 웹 기반인 ExitMe 가 접근성
   면에서 우위를 가질 수 있음을 시사한다.

## 6. 미확인·후속 조사 항목

- 공식 요금표(등급·가격·결제 주기) 1차 확인.
- 시계열 백테스트 엔진 존재 여부와 방식(룩어헤드·생존편향 처리).
- 데이터 출처(제공 벤더)와 갱신 주기.
