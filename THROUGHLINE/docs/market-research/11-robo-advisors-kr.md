# 11. 국내 로보어드바이저(일임형) — 핀트 / 파운트 / 불릴레오 / 콴텍 / 에임 — 조사일 2026-09-05

- 분류: **투자일임(디스크레셔너리) 서비스** — 사용자가 자금을 맡기면 회사가 직접 운용
- 조회 경로: 2차 자료(비교 기사·리뷰) 중심. 개별 서비스 공식 약관은 본 조사에서 미확인

## 1. 왜 비교군에 포함하나

ExitMe 와 기능은 다르지만 **"규칙 기반 운용을 개인에게 제공한다"**는 목적이 같고, 무엇보다 **과금 모델이
완전히 다른 축**(구독료가 아니라 **자산·성과 기반 보수**)이라 가격 설계 관점의 대조군으로 가치가 있다.

## 2. 시장 현황 (2차 자료)

- 주요 4사(핀트·콴텍·에임·파운트) 합산 운용자산 **2025년 기준 약 3,483억 원** — 2023년 말 1,186억 원
  대비 약 3배 성장.
- 출시 시기: 파운트 2018-05, 핀트 2019-04(국내 최초 비대면 일임), 불릴레오 2019-12.

## 3. 기능 특성

| 축 | 로보어드바이저(일임) | ExitMe |
|---|---|---|
| 자금 통제 | **회사가 운용**(일임 계약) | 사용자가 직접 발주 |
| 전략 공개 | 비공개(블랙박스에 가까움) | 정본 문서로 규칙 공개, 계산 근거 화면 제공 |
| 사용자 개입 | 위험성향 설정 정도 | 파라미터 조정·시뮬레이션·부분 이행 자유 |
| 규제 | 투자일임업 인가 필요 | 해당 없음(도구·기록 소프트웨어) |

## 4. 유료화 모델 — 자산/성과 기반 보수

- 크게 **고정보수형**(연 % of AUM)과 **성과보수형**(이익의 일정 %)로 갈린다. 자료에 따르면
  성과보수형은 "100만원 수익 시 15만원 수수료" 수준(≈이익의 15%)이 언급되며, 저비용 상품군은
  **연 0.25% 이하**로 인용된다. **개별 서비스별 정확한 요율은 본 조사에서 미확인**.
- 구독형(월 정액)과의 결정적 차이: **수익이 나야 수수료가 커지는 구조**(성과보수) 또는 **자산이 클수록
  비싸지는 구조**(고정보수). 소액 사용자에게는 구독형보다 유리할 수 있고, 큰 자산에서는 반대.

## 5. 시사점

1. ExitMe 가 만약 유료화한다면, **일임(AUM 과금)은 규제상 불가 영역**이다 — 인가 없이는 자금을
   운용할 수 없다. 남는 선택지는 도구형 구독(월정액) 또는 기능 한도 과금뿐이다.
2. 반대로 **"내 돈은 내가 발주한다"는 ExitMe 의 구조는 규제 부담이 없다**는 점이 구조적 장점이다.
   자동 발주로 넘어갈 때 이 경계(자문·일임 여부)를 반드시 재검토해야 한다.
3. 전략 비공개가 일반적인 시장에서, ExitMe 는 정본 문서·계산 근거·파라미터 공개(관리자)라는 반대
   포지션을 취한다 — 개인 도구로서는 신뢰 형성에 유리하나, 공개 서비스가 되면 **일반 사용자에게는
   공식 노출을 제한**(이미 구현한 권한 분리)하는 균형이 필요하다.

## 6. 미확인·후속 조사 항목

- 서비스별 정확한 보수 체계(고정/성과, 요율, 최소 가입금액) 공식 약관 확인.
- 국내 규제상 "투자자문/일임" 경계와 자동 발주 도구의 법적 위치.
