# 07. TradingView — 조사일 2026-09-05

- 공식: https://kr.tradingview.com/ (요금 /pricing/)
- 분류: 글로벌 **차트·전략 테스터(Pine Script)·알림 + 브로커 연동 주문** 플랫폼
- 조회 경로: 공식 한국어 요금 페이지(직접)

## 1. 서비스 개요

세계에서 가장 널리 쓰이는 차트 플랫폼. ExitMe 와 겹치는 지점은 ① **전략 테스터(백테스트)**,
② **알림(신호 통보)**, ③ **브로커 연동 주문**이다. 다만 성격은 "자체 전략 운용 시스템"이 아니라
**범용 도구**이며, 전략은 Pine Script 로 사용자가 직접 작성한다.

## 2. 기능별 정리

| 기능 | 내용 |
|---|---|
| 차트·지표 | 차트당 지표 수가 플랜별 제한(2 → 50개) |
| 전략 테스터 | Pine Script 전략의 과거 성과 검증. **무료(Basic) 플랜은 미지원**, 유료부터 사용 |
| 알림 | 가격 알림·기술적 알림 개수가 과금 축(3/20 → 1,000/1,000) |
| 브로커 연동 | 모든 **유료 플랜에서 연동 브로커를 통한 주문** 가능(플랫폼 자체는 브로커 아님) |
| 멀티 디바이스 | 웹·데스크톱·모바일, 유료는 광고 제거 |

## 3. 유료화 모델 — "한도(quota) 기반 계단식 구독"

| 플랜 | 월 가격(USD) | 연 가격(USD) | 차트당 지표 | 가격 알림 | 기술 알림 | 백테스트 |
|---|---|---|---|---|---|---|
| Basic | 무료 | — | 2 | 3 | 20 | 미지원 |
| Essential | $12.95 | $155.40 | 5 | 20 | 20 | 지원 |
| Plus | $29.95 | $359.40 | 10 | 100 | 100 | 지원 |

- 연간 결제 시 최대 17% 절약 안내(위 표의 연 가격은 월가×12 와 같아, **표기된 월 가격이 이미
  연간 결제 기준일 가능성**이 있다 — 월 단위 결제 정가는 결제 화면 1차 확인 필요).
- 과금 축이 "기능 유무"보다 **한도(지표·알림·레이아웃 수)** 라는 점이 특징. 백테스트만 무료/유료 경계.

## 4. ExitMe 와의 비교

| 축 | TradingView | ExitMe |
|---|---|---|
| 전략 | 사용자가 Pine Script 작성 | 정본 전략 고정 |
| 백테스트 | 유료 기능(전략 테스터) | 무제한 |
| 신호 전달 | 알림(개수 과금) | 주문표 화면·일지 |
| 주문 | 연동 브로커 통한 수동/반자동 | 사용자 HTS 수동 |
| 성과 추적 | 별도 기능 아님(브로커 화면) | TWR/XIRR·일지·계획 대조 |
| 과금 | 한도 계단식 구독 | 없음 |

## 5. 시사점

1. **알림 개수를 과금 단위로 쓰는 모델**은 "신호 전달"이 상품이 될 수 있음을 보여준다. ExitMe 의
   주문표는 현재 화면 확인식인데, 푸시/메일 알림을 붙이면 동일 축이 생긴다(운영 비용도 함께).
2. **백테스트를 무료 티어에서 아예 제외**하는 정책은 연산 비용이 큰 기능의 전형적 처리다.
3. TradingView 는 "차트+알림"의 범용 도구라 전략 운용의 일관성(계획 보존·체결 대조)은 제공하지 않는다 —
   ExitMe 의 차별점이 바로 그 지점(계획 스냅샷 불변, 공식 동결, TWR/XIRR).

## 6. 미확인·후속 조사 항목

- 월 단위 결제 정가(연간 결제가와의 차이) 1차 확인.
- 한국 시장(KRX) 실시간 데이터 추가 요금 및 국내 증권사 연동 가능 범위.
