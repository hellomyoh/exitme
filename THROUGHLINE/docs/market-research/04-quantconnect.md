# 04. QuantConnect — 조사일 2026-09-05

- 공식: https://www.quantconnect.com/ (요금 https://www.quantconnect.com/pricing)
- 분류: 해외 **코드 기반(Python/C#) 클라우드 퀀트 플랫폼** — 리서치·백테스트·라이브 자동매매 일괄 제공
- 조회 경로: 공식 요금 페이지(직접), 가격 수치는 2차 자료 다수(값이 서로 달라 아래에 불일치 명시)

## 1. 서비스 개요

LEAN 오픈소스 엔진 위에 세운 클라우드 플랫폼. 사용자가 알고리즘을 코드로 작성하면 **institutional급
데이터로 백테스트 → 브로커 연결 라이브 트레이딩**까지 한 파이프라인에서 처리된다. 개인 리테일부터
소형 운용사까지를 대상으로 하며, 커뮤니티·전략 마켓(Alpha Streams 계열)도 운영해 왔다.

## 2. 기능별 정리

| 기능 | 내용 |
|---|---|
| 전략 작성 | Python / C# 코드(LEAN API). 노코드 아님 — 진입 장벽이 높은 대신 표현력 무제한 |
| 백테스트 | 이벤트 드리븐 엔진, 클라우드 **백테스트 노드** 단위로 병렬 실행(플랜별 노드 수 제한) |
| 리서치 | Jupyter 기반 **리서치 노드** 별도 제공 |
| 데이터 | 주식·옵션·선물·FX·크립토 등 다자산. **틱/초 단위 데이터는 상위 플랜에서만** 개방 |
| 라이브 트레이딩 | **라이브 노드**를 사서 알고리즘을 상시 구동. 브로커 15곳 이상 연동 — Interactive Brokers, Charles Schwab, TradeStation, Alpaca, tastytrade, Binance, Kraken, Coinbase, Zerodha 등 |
| 알림 | 라이브 알림 발송 한도가 플랜별로 상이(예: 시간당 20건 → 3,600건), SMS 는 크레딧(QCC) 차감 |
| 배포 | 최상위(Institution) 는 온프레미스 배포·AES-256 등 기업 요구사항 대응 |

## 3. 유료화 모델 — "좌석(seat) + 컴퓨트 노드 종량"

구조가 명확하다: **좌석 등급(Free / Researcher / Team / Trading Firm / Institution)** 을 고르고,
거기에 **백테스트·리서치·라이브 노드를 추가 구매**한다. 즉 고정 구독료 + 사용 자원 과금의 혼합형.

| 플랜 | 백테스트 노드 | 리서치 노드 | 데이터 | 라이브 |
|---|---|---|---|---|
| Free | 1 | 1 | 제한적 | 불가 |
| Researcher | 2 | 1 | 틱/초 제외 | 노드 2 |
| Team | 10 | 10 | 전체 | 노드 10 |
| Trading Firm | 무제한 | 무제한 | 전체 | 무제한 |
| Institution | 무제한 | 무제한 | 전체 | 무제한 + 온프레미스 |

### 가격에 대한 주의 (중요)

공식 요금 페이지 본문에서는 **월 가격이 텍스트로 노출되지 않았고**(구성만 표기), 2차 자료들이 서로 다른
금액을 제시한다 — 같은 "Researcher"를 두고 월 $10 과 월 $60 이 동시에 인용되고, 라이브 트레이딩
실사용 대역으로 월 $120, 최상위 월 $1,080 이 언급된다. 노드 추가 비용은 **월 $24(1 CPU/1GB) ~
$1,000(GPU 24코어/128GB)**, 애드온 시작가는 백테스트 $10 / 리서치 $10 / 라이브 호스트 $20 수준으로
인용된다. **본 문서는 이 수치들을 확정값으로 채택하지 않는다** — 결제 화면 1차 확인이 필요하다.

정확한 것은 **모델의 형태**다: ① 무료 티어가 존재하되 라이브 트레이딩은 불가, ② 데이터 해상도(틱/초)가
상위 플랜의 판매 포인트, ③ 연산 자원(노드)이 개별 과금 단위, ④ 기업용은 배포 형태로 차별화.

## 4. ExitMe 와의 비교

| 축 | QuantConnect | ExitMe |
|---|---|---|
| 전략 표현 | 코드(무제한) | 고정 전략 + 파라미터 |
| 대상 사용자 | 개발 가능한 퀀트 | 개인 운용자(비개발) |
| 백테스트 자원 | 노드 과금(유료) | 자체 서버 무제한 |
| 라이브 | 브로커 API 자동매매(핵심 유료 기능) | 주문표 수동 발주 |
| 데이터 | 벤더 다자산 번들 | KIS API 자체 적재(한국·미국 일부) |
| 과금 | 좌석 + 노드 종량 | 없음 |

## 5. 시사점

1. **라이브 트레이딩을 "노드(상시 구동 호스트)" 라는 인프라 단위로 파는 것**이 이 시장의 표준 과금
   형태다. ExitMe 가 자동 발주로 확장한다면 "상시 구동 프로세스 = 원가"라는 동일 구조에 놓인다.
2. 무료 티어에서 백테스트는 열되 **라이브는 막는 경계선**이 일관되게 관찰된다(젠포트도 실전 연동에
   자격 제한). 검증은 무료, 실행은 유료라는 가치 분할.
3. 코드 기반이라 표현력은 최고지만 진입 장벽이 크다 — ExitMe 처럼 전략을 고정하고 UI 를 단순화한
   제품은 반대편 극단으로, 두 시장은 사용자층이 다르다.

## 6. 미확인·후속 조사 항목

- 플랜별 현행 월 가격(결제 화면 1차 확인) — 2차 자료 간 불일치 해소 필요.
- 데이터 라이선스 범위(한국 주식 커버 여부) 및 KRX 데이터 제공 유무.
