# 08. 매매일지 서비스군 — TradeZella / TraderSync / Tradervue — 조사일 2026-09-05

- 공식: https://www.tradezella.com/ · https://tradersync.com/ · https://www.tradervue.com/
- 분류: **트레이딩 저널(매매일지) + 성과 분석** SaaS — ExitMe 의 "주식 매매일지" 메뉴와 정면 대응
- 조회 경로: TradeZella 공식 요금 페이지(직접), TraderSync·Tradervue 는 2차 자료(리뷰 다수 교차 확인)

## 1. 카테고리 개요

매매 기록을 브로커에서 자동으로 끌어와(동기화) **승률·손익비·보유기간·시간대별 성과** 등으로 분해해
주고, 노트·태그·리플레이로 복기를 돕는 시장. ExitMe 의 매매일지가 *수동 입력 + 종목별 FIFO 계산*인
반면, 이 서비스들은 **브로커 자동 동기화**를 기본 전제로 한다.

## 4. ExitMe 와의 비교

| 축 | 저널 SaaS 3종 | ExitMe 매매일지 |
|---|---|---|
| 데이터 입력 | 브로커 API 자동 동기화 | **수동 입력**(종목·수량·단가) |
| 계산 | 승률·손익비·리플레이·시간대 분석 | 종목별 FIFO 실현손익·수익률·보유기간·비용 |
| 시각화 | 리포트 대시보드 | 보유 비중 도넛 + 누적 실현손익 라인 |
| AI | 크레딧제 AI 코칭·에이전트 | 계좌 도구를 가진 챗봇(권한별 제한) |
| 전략 연계 | 별도(백테스팅은 TradeZella 만 일부) | **전략 주문표와 같은 앱** — 계획 vs 체결 대조 |
| 과금 | 월 $30~99 | 없음 |

## 5. 시사점

1. **AI 를 "크레딧"으로 파는 흐름이 이미 표준화**돼 있다(TradeZella 월 500~3,000 크레딧). ExitMe 의
   챗봇도 다중 사용자로 가면 동일한 원가 통제 장치가 필요하다 — 현재는 단일 사용자라 무제한이 가능.
2. 이 시장의 핵심 가치는 "기록의 자동화"다. ExitMe 는 수동 입력이라 이 지점에서 열위지만, **전략 계획과
   실제 체결을 같은 앱에서 대조**한다는 점은 이들 서비스에 없는 축이다(그들은 브로커 체결만 본다).
3. 월 $30 대의 가격 앵커는 국내 서비스(연 10~35만원)와도 비슷한 대역이다.

## 6. 미확인·후속 조사 항목

- Tradervue 무료 티어의 정확한 월 거래 건수 한도(30 vs 100) 1차 확인.
- TraderSync 공식 요금 페이지 1차 확인(연간 할인율 45% 검증).
- 한국 증권사(키움·NH 등) 동기화 지원 여부 — 국내 사용자 실사용 가능성 판단에 필요.
