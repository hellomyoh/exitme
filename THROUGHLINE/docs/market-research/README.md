# 유사 서비스 시장 조사 — 인덱스 (2026-09-05 착수)

사용자 지시: "ExitMe 와 유사한 서비스를 검색 엔진으로 전수 조사하고, 사이트마다 기능별 정리 +
유료화 모델 분석 → 사이트 하나씩 분석 → 저장 → 검토".

## 조사 규칙 (정확성 우선)

1. **1차 출처 우선** — 각 서비스의 공식 사이트(기능·요금 페이지)를 직접 조회한다. 2차 자료(리뷰
   블로그·비교글)는 보조로만 쓰고 그 사실을 문서에 표기한다.
2. **미확인은 미확인으로 적는다** — 로그인·결제 뒤에 있어 확인 불가한 가격은 "미확인(로그인 필요)"로
   기록하고 추정치를 쓰지 않는다.
3. **조사 시점 명기** — 요금제는 자주 바뀌므로 각 문서에 조회일을 남긴다(본 조사: 2026-09-05).
4. 통화·기간(월/연) 단위를 반드시 병기한다. 연간 결제 할인가는 월 환산도 함께.
