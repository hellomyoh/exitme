# 사용자 가이드

StockLab은 **검증(백테스트) → 실행(주문표·실전 기록) → 관리(대시보드)** 루프를 제공하는 개인 투자 도구입니다.

> 본 서비스의 모든 수치는 모의·과거 데이터 기반이며 투자 권유가 아닙니다. 실제 주문은 본인의 증권사에서 직접 수행합니다.

## 1. 차트

- 상단 툴바에서 종목 검색·주기(1분~월)·차트 타입(캔들/바/라인/Heikin-Ashi)·지표를 선택합니다.
- 좌측 툴바의 드로잉(추세선·수평선·채널·피보나치·텍스트)은 종목별로 자동 저장됩니다.
- 실전 포지션이 있으면 매수 마커·평단선·목표/손절선이 함께 표시됩니다.
- 자주 쓰는 구성을 "레이아웃"으로 저장해 전환할 수 있습니다.

## 2. 백테스트 (시뮬레이터)

1. **조건 설정**: 자본금·기간·유니버스·비용을 입력하거나 **RAVG v2.5 프리셋**을 선택합니다. 프리셋에서는 절제 플래그 5종을 켜고 끄며 모듈별 기여를 비교할 수 있습니다.
2. **실행**: 진행률이 실시간 표시되며 언제든 취소할 수 있습니다.
3. **결과**: 총수익률·CAGR·MDD·샤프·승률 KPI, 자산곡선(기본 벤치마크: KODEX 200 매수보유), 월별 히트맵, 거래내역 CSV를 확인합니다. 결과는 최대 5개까지 겹쳐 비교할 수 있습니다.
- 결과가 마음에 들면 **"실전매매로 전환"** 버튼으로 동일 파라미터의 실전 포트를 만듭니다.
- 결과에 `stale` 배지가 보이면 시세 데이터가 갱신되었다는 뜻입니다 — 재실행을 권장합니다.

## 3. 주문표 (전략 엔진)

- 매 거래일 장 마감 후, 내일의 지정가 주문 목록(그리드 매수·익절·레버리지)과 조건부 지시문(갭 취소·청산 조건)이 생성됩니다.
- **실시간 현재가 그래프 (2026-09-09)**: 주문표 아래 카드에 오늘 현재가가 10초 간격으로 흐르고, 그리드 매수·초기 진입(빨강 점선)·익절(파랑 점선)·갭 취소 기준(회색)이 가격선으로 겹쳐 보입니다. 오른쪽에 각 선까지의 거리(%)가 실시간으로 갱신되며 가장 가까운 선이 강조됩니다. '하루 전체 보기'로 창을 넓힐 수 있습니다.
- **예상 시가 (2026-09-09)**: 실행일 08:30부터 주문표의 갭 경고 아래에 동시호가 예상체결가가 1분 간격으로 갱신되어 "🕗 예상 시가 105,300원 (08:58) — 갭 기준 위, 그리드 유지" 또는 "⤫ … 이하 → 매수 생략 예정"으로 보입니다(롤오버: 최근 표본). 09:00 뒤에는 확정 시가로 바뀝니다. 예상체결가는 호가 잔량 기반 근사값이며, 실제 발주 판단은 09:01에 실제 시가로 합니다.
- **초기 진입 (2026-09-08)**: 보유 없이(현금만) 새로 시작한 포트는 첫 10거래일 동안 '초기 진입' 줄(목표 미달분의 15%, 하락장 7.5%, 전일 종가 지정가)이 하나 더 나와 첫 체결이 보통 1~2일 안에 납니다. 제목 옆에 '초기 진입 n/10일'이 표시되고, 11일째부터 사라집니다.
- "계산 근거"를 펼치면 레짐 판정·지표값·노출 계산 과정을 볼 수 있습니다.
- 자세한 규칙은 [전략 가이드](strategy-guide.md)를 참고하세요.
- **무인 매매 (2026-09-06 → 2026-09-08 단일 실행)**: 설정 › 무인 실행에서 **증권사 계좌별로** 무인 매수·무인 매도 플래그를 켭니다(하루 매수 상한 %도 여기서 — 기본 0 = 없음, 진입 속도 제한용 참고값). 이것이 유일한 스위치이고 주문표에는 승인·등록 버튼이 없습니다. 플래그가 켜진 계좌에 연결된 국내 포트는 **매 실행일 09:01 에 그 순간의 원장으로 주문표를 계산해 곧바로 발주**합니다 — 09:00 까지 등록한 입출금·체결은 그날 수량에 바로 반영되고, 09:00 이후 등록은 다음 주문표부터입니다. 09:01 에 시가를 확인해 갭 취소 기준 이하면 그리드 매수를 생략하고, 원장 보유가 계좌 잔고와 다르면 발주하지 않고 정지합니다. 매도(익절·청산)를 먼저, 매수는 레버리지 진입(시장가) → 그리드(지정가) 순으로 내며 하루 매수 상한·매수가능 수량에 맞춰 **수량을 줄여** 냅니다(정지하지 않음). 꺼진 방향의 줄은 '수동 처리'로 남습니다. 발주 2회 연속 실패나 장 마감 대조의 계획 외 거래가 있으면 그 포트는 자동으로 멈춥니다(주문표 배너의 '다시 켜기').
- **주문표 상단 상태**: 수동 모드(꺼짐) / 🤖 무인 대기 — {실행일} 09:01 발주 예정 / ⏳ 실행 중 / ✅ 완료(발주·생략·축소·실패 건수와 시가) / ✋ 무인 취소됨(수동) / ⛔ 정지(사유) / ⚠️ 09:01 실행 기록 없음(09:15 감시가 지연 실행). 표의 '무인' 열에 줄별 결과(발주됨 #주문번호·체결·갭 취소 생략·생략 사유·취소됨)가 보입니다.
- **오늘만 수동으로**: 주문표의 **[이번 실행일 무인 취소 → 수동]** — 09:00 전이면 그날 발주를 건너뛰고(되돌리기 가능), 09:01 후면 증권사에 살아 있는 무인 주문을 취소합니다. 다음 실행일에는 자동으로 무인 대기로 돌아갑니다. 설정에서 플래그를 끄면 그 방향의 오늘 미체결 무인 주문도 즉시 취소되고 다음 09:01 부터 발주하지 않습니다. 이미 체결된 주문은 취소되지 않으니 반대 매매로 정리하세요. 처음에는 모의투자 계좌로 1주부터 확인하세요.

## 4. 실전매매 기록

- 체결한 매매를 종목·수량·단가·일시로 등록합니다(차트에서 클릭 입력 가능). 추가 매수 시 평단이 자동 재계산됩니다.
- 수익률 카드에서 매수 시점 기준 수익률·보유일수·목표/손절 진행을 확인합니다. 비용 포함/제외를 토글할 수 있습니다.
- 입금·출금도 등록해야 계좌 수익률(TWR·XIRR)이 정확해집니다.
- **미국 포트의 매매 공식**: "새 실전매매 시작"에서 LTM·QLD(기본) / LTM·TQQQ / TF 중 하나를 고릅니다. 탭 줄의 "공식 …" 배지가 현재 규칙이고, "이름·색" 편집에서 바꿀 수 있습니다(다음 주문표부터 적용). 어떤 공식을 고를지는 가이드 개요의 비교 그래프를 참고하세요.
- **계좌에서 불러오기 (2026-09-06)**: "새 실전매매 시작"에서 증권사 계좌를 고르고 "계좌에서 불러오기"를 누르면 D+2 예수금이 현금 칸에, 계좌의 전략 종목 보유(200 ETF·레버리지)가 보유분 행에 채워집니다. 전략 외 종목은 제외 목록으로만 보입니다. 값은 확인·수정한 뒤 "시작하기"를 누르세요 — 한 계좌를 매매일지나 다른 포트와 함께 쓰면 예수금 전체가 이 전략의 몫이 아닐 수 있습니다. 시작하면 그 계좌가 바로 연결됩니다.
- **예수금 대조 (2026-09-06)**: 계좌가 연결된 국내 포트는 장 마감 동기화(15:45)가 체결을 가져온 뒤 원장 현금과 계좌 D+2 예수금을 비교합니다. 수수료·분배금 범위(1만원 또는 총자산 0.1%)를 넘는 차이가 있으면 주문표 위에 경고가 뜹니다. 자동으로 고치지 않으며, 앱 밖 입출금·수수료·분배금이 원인이면 "차액을 입출금으로 등록"으로 한 번에 맞추고, 체결 누락이면 "최근 7일 체결 조회"로 가져오세요. 증권사 연동 카드의 "지금 대조"로 언제든 다시 확인할 수 있습니다.

### 4-2. 계좌 평가금액 (2026-09-06)

- 일지가 연결 계좌의 주식을 **전부** 담고 있으면 "계좌 평가금액" 카드가 나타납니다. 값은 주식 평가액 + 예수금이고, 보조 줄에 구성이 표시됩니다.
- 일지가 계좌의 일부만 담고 있거나(계좌에 없는 종목이 일지에 있거나 수량이 다르면) 카드는 숨겨집니다 — 그 경우 합계가 계좌 총액도 일지 총액도 아니기 때문입니다.
- 예수금은 D+2 정산 기준이라 매도 직후 인출 가능액과 다를 수 있습니다. **대시보드 총자산에는 주식 평가액만** 반영됩니다(한 계좌를 여러 일지에 연결하면 예수금이 중복되므로).

### 4-1. 매매일지 현황 그래프 (2026-09-06)

- 현황 카드 오른쪽에 탭이 두 개 있습니다. **보유 수익률 (%)** 는 보유 종목의 "그날 종가 ÷ 그날 시점 평단 − 1"을 첫 매수일부터 그립니다. 추가 매수·부분 매도로 평단이 바뀐 날부터 반영되고, 연결 계좌가 있으면 마지막 점은 현재가입니다. **누적 실현손익 (원)** 는 매도 기록으로 계산한 종목별 누적 실현손익입니다.
- 보유 종목이 둘 이상이면 검은 점선으로 일지 종합 수익률이 함께 그려집니다. 청산한 종목은 "청산 종목 보기"로 보유 구간만 점선으로 볼 수 있습니다.
- 시세는 DB 일봉을 쓰고 부족하면 KIS 일봉으로 받아 채웁니다(일지에 연결한 증권사 계좌 키 또는 .env 시세 키). 수동으로 넣은 종목은 **종목코드(선택)** 를 함께 입력해야 시세가 붙습니다.

### 4-4. 텔레그램 알림 (2026-09-07)

- 설정 › 알림에서 봇을 연결합니다. 텔레그램 @BotFather 에게 `/newbot` 을 보내 봇을 만들고 토큰을 붙여넣어 저장한 뒤, 텔레그램에서 그 봇에게 아무 메시지나 보내고 "연결 확인"을 누르면 채팅 ID가 자동으로 채워지고 테스트 메시지가 옵니다. 토큰은 암호화 저장되며 화면에는 마스킹으로만 보입니다.
- "알림 보내기"를 켜고 보낼 항목을 체크합니다. 연결 확인이 성공하면 알림 보내기가 자동으로 켜지고, 꺼져 있으면 화면 상단에 경고와 '지금 켜기'가 보입니다(2026-09-09). 항목은 무인 실행 결과, 자동 승인 결과, 사전 갭 취소, 정지·긴급 정지, 장 마감 동기화, 예수금 대조, 주문 접수·취소·설정, 체결 등록, 일일 현황(16:40 총자산·전일 대비·포트별 평가액)입니다. 결과·경고 항목은 기본으로 켜져 있고 주문·체결 등록은 꺼져 있습니다.
- 메시지는 서버가 기록을 남기는 시점에 바로 옵니다. 전송이 실패해도 본 작업(발주·동기화)은 계속되고 매매 로그에 "알림 전송 실패"로 남습니다.
- 챗봇에게 "무인 실행 상태 알려줘", "왜 오늘 발주가 안 됐어?" 같은 질문을 하면 무인 운영 상태와 매매 로그를 조회해 답합니다.

### 4-3. 매매 로그 (2026-09-06)

- 왼쪽 메뉴 "매매 로그"에서 거래·주문·이벤트를 한 표로 봅니다. **거래**는 거래 원장(수동 등록·증권사 가져오기·예수금 보정), **주문**은 예약주문·무인 실행 줄의 현재 상태(접수·발주·체결·미체결·취소·생략·실패)와 증권사 메시지, **이벤트**는 무인 실행·사전 갭 취소·장 마감 동기화·예수금 대조 등의 과정 기록입니다.
- 실패한 거래·주문은 "수준 › 경고 이상만(실패 포함)" 또는 "오류만"으로 모아 볼 수 있습니다. 기간(7일~1년)·유형·실전매매·검색으로 좁힐 수 있습니다.
- 삭제한 거래는 원장에서 사라지지만 "거래 삭제" 이벤트로 남습니다.

## 5. 대시보드

- 최상단에 총자산과 전일대비가 표시됩니다. 자산 구성(주식/현금/기타), 자산 추이, 일간 손익 캘린더, 현재 레짐·노출 게이지를 확인합니다.
- 예금·펀드 등 기타 자산은 수동으로 등록·갱신합니다.
- 매매일지 자산은 진행 중 일지의 보유를 현재가(없으면 취득원가)로 평가해 총자산에 넣습니다. 일지와 같은 증권사 계좌를 쓰는 실전매매 포트가 **실제로 보유한 종목**만 일지에서 빼서 같은 주식이 두 번 세어지지 않게 합니다(2026-09-06). 표의 마지막 열이 "포함 / 일부 포함 — 제외 종목 / 제외"로 상태를 보여 줍니다.
- 모든 화면 하단에는 시세 기준시각과 지연 여부가 표기됩니다.

## 6. 가이드 (매매 공식 설명)

- 사이드바 **📖 가이드** 그룹에 매매 공식별 설명 페이지가 있습니다 (2026-09-06 신설). 수식과 상수 없이 "무엇을 왜 하는지"만 설명합니다.
- **매매 공식 개요**: 세 공식(RAVG · TF · LTM) 비교표, 공식별 비교 블록(같은 최대 낙폭으로 맞춘 보유와의 수익 비교 → 자산곡선 → 낙폭 그래프 → 위기 구간 표 → −20% 아래 체류 시간 → 연도별 수익), 공통 원칙, 시뮬레이터→실전 흐름, 용어 사전. 수익률만 보면 오르는 장에서는 보유가 이기므로 "같은 위험에서 더 버는가"와 "위기 구간에서 덜 빠지는가"로 봅니다.
- **RAVG · 한국**: 레짐 → 노출 → 그리드 → 매도 → 레버리지 두 트랙 → 안전장치 → 하루 흐름 → 주문표 라벨 순서. 한국 주문표를 읽을 때 1~6번을 차례로 보면 됩니다.
- **TF · 미국 1배**: 두 줄 규칙과 2% 완충, 200일선을 쓰는 이유, 실측 요약.
- **LTM · 미국 레버리지**: 세 층 구조(보유 게이트 · 레버리지 허용 조건 · 비중), 안전장치(1년 수익·급락 브레이커·밴드·현금 여유), 실측과 한국 미적용 이유.
- 정확한 계산식은 [전략 가이드](strategy-guide.md)·기능 명세([feature-us-trendfilter](../features/feature-us-trendfilter.md), [feature-us-ltm](../features/feature-us-ltm.md))를 참고하세요.
