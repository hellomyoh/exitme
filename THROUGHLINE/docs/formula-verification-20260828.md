## 치명 (전략 오동작 → 직접 손실 경로)

## 경 (표시·엣지)

- 시장가 **매수**에 슬리피지 적용 (§5.2 는 청산에만) → 제거 / 벤치마크 진입 신호일 종가 → 익일 시가
- 로트 취득단가 `int()` 절사 → 반올림 / CAGR 이 final≤0 에서 복소수 → None 가드
- `round_tick` 부동소수 경계 (몫 9자리 반올림 후 floor/ceil) / tp 체결의 로트 동일성 판정 `in`(값 비교) → `is`(identity)
- 저널 day_pnl 이 표시 equity 증분과 ±1원 불일치 → 반올림 후 차분
- XIRR 브래킷 [−0.99, 10] → 단기 고수익에서 해 없음 → 상한 자동 확장(≤1e6), 종료 평가일 KST
- 현금 초과 출금 허용 → 409 / 최고·최저 도달 수익률이 현재 평단을 과거 전 구간에 적용 → 시점별 평단(FIFO 재생)
- 스냅샷·추이 날짜 UTC `date.today()` → `kst_today()` / 포트 기준 주문표: 로트 정렬 결정론 + 전략 외 종목 409
