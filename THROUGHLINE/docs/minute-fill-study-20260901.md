## 발견 1 — 데이터 기준 불일치 (실사용 시 주의)

분봉과 일봉이 **다른 가격 기준**이었다: 일봉 = 원주가(수정계수 별도), 분봉 = 분배락 반영 수정주가.
비율이 계단형(069500: 1.0→1.002→…→1.01 6단계, 122630: 0.9963/1.0)으로 확인 — 연중 분배 이벤트 누적.
보정 없이 섞으면 그리드가 허위 체결되어 1년 +13.9%p 의 가짜 개선이 나온다. **일자별 종가 비율로
분봉을 재스케일**해 해결. → 분봉을 실제 용도로 쓰려면 수정주가 정합 처리가 선행돼야 한다.
