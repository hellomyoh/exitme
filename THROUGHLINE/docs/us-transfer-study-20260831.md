# 한·미 동일 알고리즘 적용 타당성 검증 — 2026-08-31

사용자 지시: "미국과 한국 주식 매매에 동일한 알고리즘을 적용해도 문제가 없을지 검증하라."

[미국 이식 백테스트](us-backtest-20260831.md)의 후속 검증이다. 이식 백테스트가 "전략이 성립한다"를 보였다면,
본 검증은 ① 파라미터 이식성(재보정 없이 안전한가), ② 시장 특성 차이의 영향, ③ 백테스트가 생략한 경제 요소,
④ 운영 인프라 관점의 문제를 각각 실증한다.

## 실행 조건

| 항목 | 값 |
|---|---|
| 데이터 | DB `ohlcv_daily` (KIS 수집분) — QQQ+QLD 2007-08-21~2026-08-28 4,786봉 / 069500+122630 2017-01-02~2026-08-31 2,368봉 |
| 주의 | DB 의 2026-08-31 QQQ/QLD 봉은 **미완성 봉**(프리마켓 시점 수집, 거래량 20만 vs 평소 3,400만)이라 검증에서 제외 |
| 미국 비용 | [이식 백테스트](us-backtest-20260831.md)와 동일 — $1M, 수수료 0.1%·슬리피지 0.1%(청산)·보수 0.20%/0.95% 일할·세전 |
| IS / OOS | 미국 2007~2018 / 2019~ (OOS 는 전체 워밍업 후 start_index 절단), 한국 2017~2022 / 2023~ |

## 1. 파라미터 이식성 — KOSPI 기준값은 미국에서도 고원 위 (문제없음)

핵심 파라미터 6종을 기준값 대비 큰 폭으로 변형해 미국 데이터에서 스윕했다 (레짐 규칙은 현행 ε=0):

| 변형 | FULL 수익 / 샤프 | MDD | IS 수익/샤프 | OOS 수익/샤프 |
|---|---:|---:|---:|---:|
| **KOSPI 기준값 그대로** | **+469.0% / 0.79** | −21.1% | +121.2% / 0.68 | +151.5% / 0.90 |
| target_downside_vol 0.10 / 0.16 | +420.8~+520.7% / 0.79~0.80 | −21% | +111.8~+145.1% | +140.9~+148.3% |
| emax_bull 1.15 / 1.45 | +448.6~+459.6% / 0.77~0.79 | −20.1~−23.3% | +112.5~+127.2% | +136.5~+158.0% |
| grid_coef 0.5 / 1.0 | +446.3~+495.5% / 0.79~0.80 | −21~−22% | +113.1~+124.5% | +151.1~+160.0% |
| sigma20_liquidate 0.20 / 0.30 | +439.3~+464.8% / 0.77~0.79 | −21% | +117.4~+122.4% | +142.9~+148.7% |
| regime_buffer(MA20/60) 0.03 / 0.05 | +520.6~+522.4% / **0.82** | −21.1% | +134.4~+135.5% | +158.9% |
| emax_neutral 0.50 / 0.80 | +465.1~+466.7% / 0.78~0.79 | −21.8% | +117.0~+122.5% | +149.0~+155.4% |

- 12개 변형 전부 샤프 0.77~0.82 의 좁은 띠 안 — **어느 방향에도 절벽이 없고 KOSPI 기준값은 고원 중앙에 있다.**
- 유일하게 일관된 개선은 MA20/60 완충 3%(IS·OOS 동시 개선, 샤프 0.79→0.82). 미국 전용 재보정의 기대 이득은
  ~10% 수준으로, [이식 백테스트](us-backtest-20260831.md) 결론의 "재보정 필수"는 "재보정 없이도 성립하나 개선 여지"로 완화한다.

## 2. 시장 특성 차이 — 알고리즘은 견디지만 기회비용이 더 크다

| 진단 (기준값 실행) | 미국 (QQQ, 18.9년) | 한국 (069500, 9.6년) |
|---|---:|---:|
| 레짐 분포 상승/중립/하락 | 72 / 14 / 14% | 44 / 21 / 35% |
| 레짐 전환 | 135회 (7.1회/년) | 83회 (8.6회/년) |
| σ20 중앙값 / >25%(청산 임계) 일수 비중 | 17.1% / **21.9%** | 16.4% / 14.0% |
| 레버리지 강제청산 | 77회 (4.1회/년) | 35회 (3.6회/년) |
| BULL 일 중 E 상한 포화 | 49% | 42% |

나스닥은 더 오래 상승하고 더 자주 고변동 구간에 들어가 강제청산→재진입 왕복이 잦다. B&H 대비 CAGR 갭(10% vs 17%)이
한국보다 큰 것은 이 성격 차이에서 오는 것으로, "수익 일부 포기 + MDD 절반(−21% vs −53%)"이라는 설계 트레이드오프의
연장이지 오작동이 아니다.

## 3. 백테스트가 생략한 경제 요소 — 실질 문제는 여기

- **양도소득세 22%**: 백테스트는 세전이다. 연 단위 손익통산 + 기본공제($1,800 상당) 후 22%를 근사 적용하면
  **+469% → +293% (CAGR 9.59% → 7.47%)**. 이 전략은 연 60건+ 실현매매라 과세이연이 불가능해 B&H 보다 세금에
  구조적으로 더 취약하다. 국내는 069500 비과세·122630 15.4%가 이미 엔진에 반영되어 있으므로,
  **세후 기준의 한·미 비교는 세전 표와 상당히 다르다.** (근사 계산 — 이월공제 없음·연말 일괄 납부 가정)
- **환율**: 원화 투자자의 원/달러 노출이 완전히 미모델이다 (연 ±10% 수준 변동이 수익·MDD 에 가산).
  DB 에 FX 시계열이 없어 정량화하지 못했다 — 적용 전 환헤지 정책 결정이 선행되어야 한다.

## 4. 운영 인프라 — 한국 장 전제. 실데이터 결함 1건 발견 (조치 필요)

1. **미완성 봉 영구 오염 (실증)**: DB 에 2026-08-31 QQQ/QLD 봉이 존재하는데, 적재 시각 21:12 KST = 미국 프리마켓
   08:12 ET 의 미완성 봉이다(거래량 20만). 적재는 `ON CONFLICT DO NOTHING`(원본 UPDATE 금지, ADR-002)이고
   `ingest_us_daily` 증분 로직은 마지막 저장일에서 멈추므로 **진짜 봉으로 자동 교체·복구되지 않는다.**
   → 해당 봉 삭제 + "미 장마감 확정 후에만 당일 봉 저장" 가드 필요. ([TODO](../TODO.md) 버그 등록)
2. 일일 수집 배치는 KST 16:05·한국 캘린더·국내 API 전용 — 미국 봉은 일일 배치로 갱신되지 않는다
   (`ingest_us_daily` 는 스케줄 없는 스크립트 경로). 미국 휴장 캘린더·DST 대응도 없다.
3. 시그널 엔진은 `SUPPORTED={069500,102110,122630}` 하드코딩 — 미국 종목쌍 미지원.
4. `daily_ingest` 가 instruments 전체를 순회하므로 미국 종목에서 예외가 나면 `daily_signal` 이 국내 종목까지
   스킵된다(배치 status ok 조건). TEST 종목 전례상 빈 응답으로 조용히 지나갈 가능성이 높으나 실배치 1회 관찰로 확인 필요.

## 종합 판정

**계산 로직(레짐·노출·그리드·레버리지 2트랙)은 두 시장에서 동일하게 성립하며, KOSPI 파라미터 그대로도 무너지지
않는다 (§1 고원).** 그러나 실매매 확장은 다음 선결 조건을 요구한다:

1. 미국용 Params 프로필 (비용·tick 은 이식 백테스트 값, MA20/60 완충 3% 검토)
2. 미국 수집 배치 신설 — 미 장마감 후 실행, 확정 봉만 저장, 미국 휴장 캘린더 + 오염된 2026-08-31 봉 삭제
3. 시그널 엔진 미국 종목쌍 지원
4. 환헤지 정책 결정 (미모델 리스크)
5. 세후 수익률 기준 재평가 — 양도세 22% 반영 시 CAGR ~7.5%로, 이 수익률이 투자 목적에 부합하는지 판단

> 본 리포트는 모의 계산이며 투자 권유가 아니다. 세금 근사는 단순화 모델이고, 미국 표본은 나스닥 초강세
> 19년 단일 구간이라는 체제 편향이 있다. 실험은 전부 파라미터 주입으로 수행했으며 리포지토리 코드는 변경하지 않았다.
