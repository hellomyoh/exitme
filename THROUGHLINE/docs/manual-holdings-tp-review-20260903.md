## 측정 (판정 근거)

직전 보유 대비 매도 비율을 집계:

| 지표 | 값 |
|---|---|
| 익절 발생일 | 27일 / 약 10년 |
| 매도 비율 중앙값 | **100%** |
| 평균 | 78.1% |
| 전량(≥99%) 비중 | **59.3%** |
| 절반 이상 비중 | 77.8% |

로트가 여러 개인 정본 모델도 익절가가 종가 부근에 밀집해, 급등 하루에 대부분·전부가
함께 체결된다. 즉 "전량 익절"은 단일 로트 근사의 부작용이 아니라 설계의 전형적 행동.

## 결론

1. **전량 익절 주문은 설계 정합** — 지정가 조건부 주문이며, +Grid% 급등 시 이익
   실현 후 그리드 재진입이 의도된 왕복. 목표 노출은 현재가 기준의 오늘 목표로,
   익절 규칙과 별개 축.
2. **평단 역계산 재구성 기각** — (a) 평단<종가면 재구성 로트의 익절가가 이미 도달
   → 즉시 전량 매도 결함 재발(2026-08-28 확인된 함정), (b) 동일 평단을 만드는 분해가
   무한(임의 규칙화). 결정적으로 측정상 재구성의 실익 없음.
3. **등록 보유 코어 취급안(익절 제외) 기각** — 모델의 급등일 대량 매도 행동에서
   오히려 멀어짐.
4. **현행 근사 유지** — ASSUMPTIONS 2026-09-03 항목으로 확정.

## 운용 지침 (전량 매도를 원치 않는 경우)

- **부분 익절 운용은 허용되며 안전하다**: 발주는 본인 HTS 재량. 시스템은 B안(시점
  재생·상태 기반)이라 실제 체결만 등록하면 다음 주문표가 실제 보유·현금에서 재계산된다.
  장부·계획 정합에 문제 없음.
- 매도는 FIFO — 부분 익절이 쌓일수록 시딩 로트(등록 덩어리)가 먼저 소진되고, 새로
  산 그리드 로트는 순정으로 굴러간다. 시딩 로트가 0이 되는 시점부터 빈 계좌 시작과
  구조적으로 동일(수렴). 완전 소멸 전까지 근사는 "익절 기준선이 종가를 따라간다 +
  잔여 시딩분이 한 기준선에 묶인다"에 한정.
- 유의: 익절 주문은 매번 "남은 전량"으로 재계산되어 나온다(소진 전까지 큰 매도 주문
  표시가 정상). 재량 부분 익절은 사실상 다른 전략이므로 백테스트 성과와의 괴리는
  감수 — 괴리 크기는 시뮬레이터의 실전 비교 오버레이로 관찰 가능.
- **코어 예약 수량 기능(포트별 익절 제외 수량 설정)**: 제안됨, 사용자 승인 대기 —
