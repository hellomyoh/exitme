# 콜드 스타트 진입 속도 검증 — 보유 0·현금만으로 시작하는 사용자 (2026-09-08)

> 질문(사용자): "처음 시작하는 보유 주식 없는 사용자가 시작할 때 매매가 안 될 것 같다 — 시뮬레이션으로 검증하고 검토." 스크립트: 세션 스크래치 `sim_cold_start.py`(엔진 `plan()`·체결 규칙 재사용, 실행기의 하루 매수 상한 20% 축소 포함).

## 1. 조건

- KODEX 200(069500)·KODEX 레버리지(122630) 일봉 2017-01-02~2026-09-08(DB), RAVG v2.5 기본값, 자본 1억, 보유 0.
- 시작 시점 87개(2018-03-27~2025-08-04, 21거래일 간격), 각 250거래일 추적. 시작 시점 레짐은 전 구간 백테스트의 레짐 경로(가격만의 함수)를 그대로 사용 — BULL 39 · NEUTRAL 8 · **BEAR 40**.
- 체결: 시장가 = 다음날 시가, 지정가 매수 = 시가 ≤ 지정가면 시가, 저가 ≤ 지정가면 지정가, 갭 필터(시가 ≤ 종가 − 1.5·ATR)면 그리드 매수 생략, 익절 = 시가/고가 규칙. 수수료 0.015%. **하루 매수 상한 20%(총자산 대비) 축소**는 09:01 실행기와 같은 순서(시장가 → 얕은 그리드 → 깊은 그리드, 발주 시점 누적).
- 지표: 첫 K200 체결까지 일수, 실효 노출 충족률 = (K200 + 2×레버) / (E·총자산) 이 50%·90% 에 처음 닿는 일수, 5/10/20/60/120일 시점 충족률 중앙값, 250일 수익률.

## 3. 해석

1. **상승장·중립장 시작이면 매매는 된다.** 첫 체결 중앙 2~4일, 90% 가 10일 안. 그리드 1단이 종가 −1×Grid(≈−1σ) 에 걸려 있어 하루 체결 확률 ~25%(order-formula-study §3.2)이고, 상승장은 레버리지 전략 트랙이 첫날 시가로 즉시 들어간다.
2. **"매매가 안 된다"고 느끴는 경우는 하락장 시작이다** — 표본 시작 시점의 46%. 정본 §6.2 "하락장 그리드 매수 정지" 때문에 주문표에 매수 줄이 하나도 없고, 레짐이 NEUTRAL 로 돌아올 때까지(중앙 78일, 최장 250일 이상) 현금만 든다. 이어서 운용하던 사용자는 축소 매도로 20% 를 들고 하락장을 지나지만, 새 사용자는 0% 로 지난다 — 규칙상 의도된 비대칭이고 손실을 피하는 쪽이다. 문제는 **화면이 그 이유를 말하지 않는 것**(주문표가 비어 있고 상태 줄은 "오늘 주문 없음").
3. **하루 매수 상한 20% 는 목표 도달을 ~9일 늦추지만(90% 도달 30→39일) 수익률 차이는 잡음 수준**(+0.4%p). 신규 진입의 안전장치로 유지할 가치가 있다.
4. **시가 부트스트랩(C·D)은 진입은 빨라지지만 기대 수익은 낮다.** 5일 충족률 0% → 30~50% 로 체감은 좋아지나, 250일 수익률이 중앙 −0.7%p, 87개 중 62~72개 시작에서 현행보다 나쁘다 — "떨어질 때 산다"는 그리드의 진입 우위를 첫날 시가 매수가 포기하기 때문. 노출 90% 도달은 39→32~34일로 큰 차이가 없다(나머지 50% 는 어차피 그리드).

## 4. 권고

- **공식은 바꾸지 않는다.** 콜드 스타트의 느림은 하락장 정지·그리드 진입이라는 전략 규칙의 결과이고, 시가 부트스트랩은 기대 수익을 깎는다(ADR-007 정본 유지).
- **화면에서 이유를 말한다 (구현 제안, 패치):**
  - 하락장 + 보유 0: 주문표 상단에 `하락장 — 매수 정지. 중립장 전환까지 현금 대기 (레짐 MA200 회복 + 2% 필요)` 한 줄. 무인 상태 줄의 "오늘 주문 없음"에도 사유 `하락장 매수 정지` 를 붙인다.
  - 중립·상승장 + 보유 0: `첫 진입은 그리드 지정가로 — 하루 체결 확률 ≈25%, 첫 체결 중앙 2~4일, 목표 노출 도달 중앙 약 40일(하루 상한 20%)` 한 줄(첫 체결 전까지만).
- **선택지(사용자 판단, 미구현):** "빠른 진입" 옵션 — 시작일 목표의 50% 를 시가 매수(D). 진입은 3일 안에 절반, 대신 첫해 수익 중앙 −0.7%p. 원하면 포트 옵션(기본 꺼짐)으로 ADR 을 따로 낸다.
