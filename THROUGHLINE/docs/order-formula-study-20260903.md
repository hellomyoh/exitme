# 주문표 계산 공식 수리 검토 — 미분·적분 분석과 실데이터 검증 (2026-09-03)

## 1. 노출 E — 미분 분석

정본 §5.1: `E = min(Emax, α·T/σ_d + (1−α)·σ_ref/σ_d)`, α=0.5. 캡 이전 구간에서

```text
E(σ_d) = (αT + (1−α)σ_ref) / σ_d          (σ_d 의 순수 반비례 함수)
∂E/∂σ_d = −E/σ_d      ⇒      dE/E = −dσ_d/σ_d   (탄력성 = 정확히 −1)
```

- **의미**: 하방변동성 1% 상승 = 목표 노출 1% 축소. 전 구간 등탄력 — 저변동에서 과민하지도, 고변동에서 둔감하지도 않은 일관 설계. 개선 불요 판정.
- **σ̂_d 표본 노이즈 전파**: 20일 창의 σ 추정 표준오차 ≈ σ/√(2·20) = 7.9%·σ. 탄력성 −1이므로 E 에 그대로 7.9% 스케일 노이즈가 전달되나, 리밸런싱 밴드(±5%p)가 `|Δσ_d/σ_d| > 0.05/E` 미만의 잔진동을 흡수 — 밴드와 탄력성이 정합.
- **캡 구간의 무감각**: E = Emax 바인딩 시 ∂E/∂σ_d = 0 — 변동성 신호가 완전히 꺼짐. [레버리지 검증(2026-09-01)](../HISTORY.md)에서 실측한 "BULL 의 63%에서 캡 고정"과 동일 현상의 해석적 표현. 기존 결론(재검토 후보) 유지.

## 2. 배분 공식 — 도함수와 회전율

`w_200 = min(E, 2−E)`, `w_LEV = max(0, E−1)`:

```text
E < 1:  dw_200/dE = +1, dw_LEV/dE = 0   → 신호 1단위당 회전율 |Δw| 합 = 1
E > 1:  dw_200/dE = −1, dw_LEV/dE = +1  → 신호 1단위당 회전율 |Δw| 합 = 2
```

E>1 구간은 같은 신호 변화에 **거래 대금이 2배**(K200 매도 + LEV 매수 동시 발생)인 고회전 구간. 밴드 ±5%p가 1차 방어이며, 실효노출 항등식(w_200 + 2w_LEV = E)의 대수적 필연이라 공식 자체는 변경 불가 판정 — 비용은 밴드가 통제.

## 3. 그리드 — 반사원리 적분과 실데이터 캘리브레이션

### 3.1 심도의 σ 환산 (실측)

ATR/C ÷ σ₁(20일 일간수익률 표준편차) 중위 = **1.352** (순수 브라운운동 기대범위 √(8/π)≈1.596 대비 갭·평균회귀로 낮음).

```text
G = 0.75 × ATR/C ≈ 0.75 × 1.352·σ₁ = 1.01·σ₁
⇒ 그리드 사다리는 사실상 전일 종가 −1σ / −2σ / −3σ
```

### 3.2 체결 확률 — 이론 vs 실측 (2,348일)

드리프트 0 브라운운동의 반사원리: `P(일중 저가 ≤ −x) = 2Φ(−x/σ₁)` ⇒ `p_k = 2Φ(−k·1.01)`.

| 단 | 이론 | 실측 | 실측/이론 |
|---|---:|---:|---:|
| 1 (−1σ) | 30.2% | **25.0%** | 0.83 |
| 2 (−2σ) | 5.1% | **6.3%** | 1.23 |
| 3 (−3σ) | 0.66% | **1.45%** | **2.18** |

- 1단 실측 < 이론: 상승 드리프트·개장 갭 상방 편의.
- **3단 실측 = 이론의 2.2배 — 두꺼운 꼬리 실증.** 정규가정으로는 "3단은 12년에 한 번"이지만 실제는 연 3~4회. 깊은 단에 예산을 두는 사다리 설계의 가치가 이론보다 크다는 뜻으로, 3단 구조 유지의 실증 근거.
- 3단 동시 관통일 1.45%(34일) — 갭 필터(−1.5·ATR = −2.03σ)가 이 날들의 일부를 차단하는 이중 방어와 정합.

### 3.3 clip 경계의 역산

`G_raw = 1.014σ₁` 이므로 clip 은 σ 로 환산하면: 하한 0.8% 바인딩 ⇔ σ_ann < ~12.5% (**일수의 18.1%**, 저변동장에서 그리드가 σ 기준 깊어짐 = 보수화), 상한 4% ⇔ σ_ann > ~53% (**2.0%**, 위기장에서 σ 기준 얕아짐). 상한 완화(6%) 실험은 성과 무영향(+230.6% vs +230.8%) — 바인딩 일수 대부분이 그리드 정지(BEAR) 구간과 겹침. **현행 clip 유지 판정.**
